Eidoloom Studio guide

Getting started

Eidoloom Studio is an AI agent harness with a code editor around it, in your browser: everything that turns a model into an agent (the loop that plans and calls tools, the tools, approvals and undo), with the model of your choice. The agent reads your project, edits files and runs commands, and you stay in charge: by default it asks before every change.

  1. Open a folder with the button at the top left. Everything the agent does happens inside that folder.
  2. Pick a model in the top bar: one that is good at tool calls, such as Qwen 3 or a Strata model. The first message may load the model, and a bar shows how far it is.
  3. Write what you want in the chat box on the right and press Enter. Shift+Enter starts a new line.

The screen has the file list (Explorer) on the left, the editor in the middle, terminals below it and the chat on the right. The icons on the far left switch the side bar between Explorer, Search, Source control, Skills, Video and Tasks.

Sandbox. The Sandbox switch in the top bar runs the agent's commands in a separate container for this folder, so they cannot touch the rest of the computer. File edits still change your real folder. Accounts other than admins are always sandboxed.

Working with the agent

Approvals

  • Edits show as a card with the change: Accept, Reject, or Choose parts to accept only some of the changed places. An edit you rejected is not shown again in the same run with only comments, its place or a name changed: the agent is told to ask you or try something else. A later edit that holds the rejected change with more added says so on its card, and a command that names that file asks you even with auto-run on. A command that makes the rejected change in a file anyway is caught after it runs: the file's text is put back and the change is shown to you again. Only that text is put back, not anything else the command did (other files, a database, a service), and a command that changes the file and restores it within itself is not seen.
  • Commands show the exact command: Run or Skip.
  • Auto-apply edits and Auto-run commands in the top bar stop the asking. Turn them on when you trust the task.
  • Every edit has Undo. Deleted files go to the trash in .strata-studio/trash.

While it works

  • Steer: type and press Enter while the agent works. It reads your message at its next step. Such messages are marked "Steer".
  • Queue: Alt+Enter or the list button keeps a message for when the run ends.
  • Stop with the square button. Closing the browser does not stop a run: open Studio again and it carries on in front of you.
  • The plan card shows the agent's checklist, and the line above the chat box says which step it is on.
  • When the agent needs a decision, it may ask questions with choices: pick one, several where allowed, or type your own answer. Several questions come one at a time: swipe, or use Back and Next. Skip lets it decide.

Adding context

  • Any file: paste, drop, or use Add files (the paperclip). Its ▾ also adds a file from the project (search by name) or one of the newest sounds, pictures and videos. Pictures are shown to the model (it must be one that can see; the Strata models can). Documents and text files are read into the message. Every other file, such as a sound, video, 3D model or archive, is saved in the folder's attachments/ folder, and the agent gets its path, its full path for tool servers, and a few facts such as a sound's length and sample rate, so "use this WAV as the reference" works.
  • Choosing and moving files: one click on a file in the Explorer chooses it; a double click opens it (on a phone or tablet one tap opens it). Ctrl+click (Cmd on a Mac) adds or removes a row, Shift+click chooses every row between, and Ctrl+A in the Explorer chooses all you can see. Drag the chosen rows onto a folder to move them there, or onto empty space for the top. If a name is taken, Studio asks: Replace, Keep both or Skip these. The right-click menu and the Delete key act on all the chosen rows.
  • Finding in the Explorer: the magnifier at the top of the Explorer, or Ctrl+Alt+F (or Ctrl+F while the Explorer has focus), opens a find bar. It looks for folder and file names and for text inside files at once: names first, then the lines that hold the text. A slash searches whole paths (sounds/int). Click a folder to show it in the tree, a file or a line to open it; ↑ ↓ and Enter work too, Esc closes it. Aa matches case.
  • Downloads to your computer: the download button at the top of the Explorer downloads what you chose: one file as it is, a folder or several items as one zip, or, with nothing chosen, the whole project as a zip (without node_modules, .git, virtual environments and the trash). The right-click menu has Download too. Every sound, video, picture, 3D model, PDF, table and Markdown file has a Download button where it opens, and the Media view has one per file plus Download all for everything shown.
  • Files into the folder: drop files or whole folders from your computer onto the Explorer: onto a folder to put them there, or onto empty space for the top. The upload button in the Explorer and Upload files… in its right-click menu do the same. Large files go in parts, with a progress bar. If a name is taken, Studio asks: Replace (the old file goes to the trash) or Keep both.
  • Word, Excel and other documents: Add files (or paste, drop) takes .docx, .xlsx, .pptx and OpenDocument files, up to 25 MB. The agent gets their text: headings, paragraphs, and tables and every sheet as tables (formulas as their values). PDFs and old .doc, .xls, .ppt and .rtf files work for admins, since a program on the server opens them. Documents in the folder can be named with @, and the agent reads them itself too. A file too large for the chat (more than about 200K characters of text, or a sheet over 3,000 rows) is not refused: Studio saves it in the folder's attachments/ folder, each Excel sheet also as a CSV file with every row, and the agent gets the start and reads the rest from there. Its message shows where it went.
  • New Word and Excel files: ask the agent for a report, a letter or a spreadsheet and it writes a real .docx or .xlsx file in the folder, with headings, lists, tables, a bold header row and working formulas. You approve it like an edit, seeing its text; replacing a file puts the old one in the trash, and Undo removes the new one.
  • @file mentions a file of the folder, so the agent reads it.
  • !command runs a command yourself (for example !make test); the agent sees the result with your next message.
  • Quote: select text in a reply and press the Quote button that appears.

Your messages

Hover over a message you sent (on a phone they are always shown); the buttons appear under it:

  • Copy copies the message as you typed it.
  • Rewind to here removes it and everything after it, puts it back in the box, and can also undo the agent's file edits since then.
  • Branch from here starts a new chat with everything before that message.
  • Ask again (on your latest message) sends it again in place of the old answer.

After a run

  • A card lists the files the run changed, including files its commands wrote. Click to open one, @ to mention it next.
  • Studio runs the project's tests by itself and shows whether they pass, next to what the agent claimed. Put Test command: … in STUDIO.md to choose the command.
  • Reading, listing and searching fold into one quiet line such as "Read 3 files, searched once"; click to see them.
  • Every reply has a copy button. Tables, code and math formulas are shown properly.

Codex as the agent

  • Admins can pick one of OpenAI's Codex models in the model picker (the Codex (ChatGPT) group). Studio then runs the Codex program installed on this machine with the ChatGPT account it is signed in to, and the chat works as usual: its words, the commands it runs, its edits with Undo, its plan, and the files card at the end.
  • Codex asks before commands that may change something and before every edit, with the usual cards; read-only commands pass. Auto-apply edits and Auto-run commands work for it too, and a message sent while it works reaches it at once.
  • It works in folders with the Sandbox off, in Codex's own sandbox, and it keeps its own conversation, so /compact, Time-skip and scheduled tasks stay with Studio's own models. A chat can switch to Codex later: it is told what was said before.
  • Codex uses Studio's tool servers too (pictures, video, music, voices, sound effects, sound files, Blender, web search, the browser, Greek checks, listmonk): each call shows as the usual tool row, asks first as that server is set to, and pictures come back to Codex so it can look at them. The servers' passwords and settings stay in Studio.
  • Since Codex thinks on OpenAI's servers, Studio unloads an idle Strata before Codex's first picture, video, music, voice, sound or Blender call, so those tools get the whole graphics card (not while another chat uses a Studio model). Strata loads again on its next message, in about half a minute.
  • The Codex pill in the status bar shows how much of the ChatGPT plan's Codex limits is used: the session (the 5-hour window) and the week, as two small bars. Click it for the bars with percentages and when each one resets; it updates while Codex works.
  • While a Codex model is chosen, a strip under the chat's header shows Codex's usage: the 5-hour session and the week, each with its bar and when it resets. Tap it for the details. It is there on phones too, where the status bar is hidden.
  • Account & settings → Codex (admins) shows which OpenAI account Codex uses, with its usage, and has Sign out. To sign in: With a code shows a link and a one-time code to enter on any computer or phone; With a sign-in link opens OpenAI's page, after which you paste the localhost address the browser ends on; With an API key uses a paid OpenAI API account (Studio does not keep the key). The account is shared by every admin's Codex chats.
  • With a Codex model picked, the Effort chip in the message box sets how hard Codex thinks in this chat: the levels that model offers (Low to Ultra; Ultra also hands parts to sub-agents), or the model's default. Strata models show it too: None (answer at once) to Extra high, with Medium as the gateway's default.
  • Memory after a run: when the last run ends, Studio unloads the voice, sound and music engines and has ComfyUI free its models, restarting ComfyUI if it keeps holding memory. Strata itself unloads after a while with nothing to do; set how long under Account & settings → Graphics card. The model dashboard says what was freed and when Strata will unload.
  • With a Codex model, the Goal window also has a Codex allowance: how many thousand new tokens the goal may use (what Codex writes plus what it reads that is not from its cache), and a percentage of the 5-hour limit to stop at. Codex often does a whole goal in one long turn, so Studio watches both during the turn: when one runs out it asks Codex to stop at a good point and sum up, and stops it if it starts a second call after that or keeps going for two minutes. The goal then pauses; Resume grants it again. Leave a box empty for no limit.
  • Codex may hand parts of a big task to sub-agents: each one shows as a row with its task and answer, and their commands and edits ask and appear like Codex's own.
  • Codex runs on OpenAI's servers, so what it reads leaves this machine, and every message counts against the ChatGPT plan's Codex limits. Local models keep everything here.

Trying things safely

You want to…Use
See a plan before anything changesPlan first: the chip next to Add files, or /plan your task. The agent looks around and proposes a plan, changing nothing. Then Carry out the plan, Edit the plan or Change it.
Try a change and keep it only if it worksTime-skip: /timeskip your task. The agent works on a copy of the folder; Studio runs the tests on both versions and shows the changes. Keep the update (with Undo) or Throw it away.
Be able to throw a whole run awayRun branches in Source control: each run works on its own Git branch, which you merge or delete.
Go back in the chatRewind to here on one of your messages.
In Plan first, commands that only look (such as ls, grep, git log, and the project's test command) run freely; anything else asks you, even with auto-run on, and edits are refused.

Long and big tasks

  • Goals: the Goal button beside Plan first opens a window: the goal, how to tell it is done, what to keep in mind, and at most how many rounds (20 unless you change it). Or type /goal Make every test pass. The agent keeps working in rounds until it reports the goal reached, says it is blocked, or the rounds run out. A bar above the box shows the goal, with Pause, Resume, Edit and Clear; the button shows its state and opens it again to change it.
  • Progress: the line under the messages says what the agent is doing right now. A long step (a video render, a narration, a picture) shows its own bar there, with the percentage and the time left, and on its row in the chat. A striped bar means it is working but cannot say how far along it is. Amber means it is waiting (for the graphics card, a queue, or you), not working. The percentage also shows in the browser tab's title and, on a phone, on the Chat tab. In the pinned plan, a step the agent jumped over is crossed out as skipped, not ticked.
  • Memory: the circle in the status line shows how full the model's memory of this chat is. /compact replaces the earlier messages with a summary the model writes, so it has room again; you still see the whole chat. A run that ends over 85% full offers Summarize and continue. With a model whose memory is small (an Ollama model with num_ctx), Studio shortens older tool output as it fills and, near full, summarizes the chat during the run itself, keeping your latest request.
  • A message too long for the model's memory can be saved as a file that the agent reads in parts, or shortened.
  • If the agent goes in circles (the same failing calls, the plan rewritten again and again), Studio warns it once and then stops the run with an explanation. Continue carries on from where any run stopped.

Running things on a timetable

Tasks

Open Tasks (the clock icon on the left) and press +. A task sends the agent a message every hour, day, weekday, week or few minutes, in its folder, and keeps the result.

What it may doMeaning
Look onlyPlan first: it reads and reports, and changes nothing.
Stop at what needs a yesNobody is there to approve, so edits and commands that need approval are skipped, and the result lists them.
Do everythingEdits and commands run without asking.

Each run gets its own chat (Open the chat in its details). Tasks that need attention get a badge. Runs missed while Studio is off are not made up, and three failed runs in a row pause a task. A task starts only when the agent is free.

Loops

/loop 10m check whether the build passes sends that message again in the same chat every 10 minutes. End it with words such as stop after 3 answers, for 2 hours or stop when it says passed, or type /loop stop.

Making it yours

  • Skills: the agent saves ways of working it wants to reuse, in every folder, and loads them when they fit. You can read, edit and write skills yourself in the Skills view, and find them by searching, by kind, by how often they are used, or by the folder they come from.
  • Your tools: in the Skills view, add instructions the agent can fetch (such as house rules), or a command it can run, such as a deploy script. The command receives the agent's input in $STUDIO_INPUT and asks first, like any command.
  • Chat settings (the gear above the chat): how long the model thinks for this chat (reasoning effort), a notification or sound when a run ends or waits for you while you are in another tab, and dictation with a microphone button.
  • Greek checks and the glossary: the agent checks Greek text with greek-check: spelling, and grammar such as article, adjective and noun agreement («Η κανόνας»), subject and verb («Οι ναυτικοί βλέπει»), «θα πήγα», «Που…;» and «?». Its findings come as Fix these, Check these (may be right, such as the final ν) and Notes. In Account & settings → Greek an admin keeps the house glossary: terms to avoid with what to use and why (matched in every form), and names that are right, so the speller leaves them. Everyone can read it and try the check there.
  • Themes: Dark, Light and Sepia, from the top bar.
  • Settings, chats and runs follow you to your other windows and devices.
Dictation uses the browser's speech recognition. In Chrome and Edge your voice goes to Google or Microsoft to be turned into text, so it is off until you turn it on.

Seeing results

  • Tabs: when the open files do not fit, a thin scrollbar appears under their tabs: drag it, press along it, or turn the mouse wheel over the tabs. Drag a tab sideways to move it to another place (on a touch screen, hold it a moment first); the order is kept.
  • Previews: web pages, pictures, PDFs and videos open in the editor; CSV and TSV files open as a table you can sort and search. Word, PowerPoint and OpenDocument files open as their pages, laid out as they print, and PDFs the same way, in every browser and on phones: page arrows, a page number box, Larger, Smaller and Fit (or Ctrl + wheel), and text you can select and copy. Excel workbooks open as sheets of cells with a tab per sheet, column letters, row numbers and search (formulas show their values); Page view shows them as printed pages, Sheets goes back. The pages are made on the server by LibreOffice, closed off from the network and from Studio's own files, and kept until the file changes. The code map button beside the wrap button (or Alt+M) shows or hides the small map of the file at the editor's right edge; your choice follows you to your other windows. Markdown files (.md) open as a clean document, with headings, tables, the folder's pictures and links that open other files; Edit shows the text to change, and Preview shows it as a document again, unsaved edits included. The Preview/Code button switches.
  • Live servers: when the project runs a server, the globe button in the Explorer opens it in a Live tab inside Studio. The agent can open it for you too, and look at it itself, on a computer screen or as on a phone, showing you a picture of what it saw.
  • Pictures in the chat open in an image tab with zoom, download and copy. Picture files in the project (textures too) open the same way: zoom with the mouse wheel, a pinch or + and −, drag to move, double-click to fit.

Pictures, video and voices

  • With the ComfyUI tool server, the agent makes pictures (Z-Image, SDXL, Qwen-Image), videos and music. The ComfyUI pill in the status bar (and the button with a sparkle in a frame in the top bar) opens a panel with the work being made, the queue and the default picture and music models; the layers button shows the workflow as nodes.
  • Music and sound effects: the agent makes music with generate_music (ACE-Step 1.5: songs with lyrics in 50 languages, Greek too, or instrumentals, up to 10 minutes; best quality uses the larger model and the whole graphics card) or HeartMuLa 3B (follows lyrics closely, up to 4 minutes, slower); the Music choice in the ComfyUI panel picks which one the agent uses unless you name one, and sound effects with make_sound (MOSS-SoundEffect: nature, city, animals, objects, up to 30 seconds). Both save MP3 files into your project, ready for a video timeline, and show a progress bar while they work.
  • Big models (Qwen-Image, video) unload the chat model while they work, which adds a few minutes.
  • Media: the Media view (the icon with stacked frames and a play sign) shows every sound, piece of music, picture, video and 3D model in the project, newest first: sounds play in place with their length, pictures and 3D models show as thumbnails, videos and sounds open as players, and a sound's Edit opens the wave editor. 3D models (GLB, glTF, OBJ, STL, FBX, PLY, and for admins Blender .blend files, which Blender exports first) open in a 3D viewer: drag to turn, wheel or pinch to zoom, right-drag to move; it shows meshes, triangles and size, with Reset view, Turn, Wireframe, Grid and any animations. Filter by kind, search by name, or sort (newest, oldest, name A–Z or Z–A, largest, smallest, longest, shortest, or by folder; kept per browser); Open shows it in the editor, Timeline (on a video made from a timeline) opens that timeline, and @ puts it in your next message.
  • Sounds: every sound file (MP3, WAV, FLAC, OGG, Opus, M4A) opens as a player with its waveform: click or drag on it to jump there, Play or Space, loop, and a playback volume that does not change the file. Edit (also in the Media view) opens the wave editor; Done goes back to the player and asks first if something is not saved.
  • Wave editor: drag to select a part, Shift+click to extend it, click to place the cursor; Ctrl+wheel or two fingers zoom, and the strip above shows the whole sound and moves the view. The toolbar has undo and redo, cut, copy, paste and delete, and menus: Edit (keep only the selection, silence it, insert silence), Volume (fade in, fade out, louder or quieter, normalize to the loudest point or the overall loudness), Time (speed with or without the pitch, pitch, reverse), Effects (reverb, echo, chorus, flanger, phaser, tremolo, vibrato, low- and high-pass, bass, treble, compressor, noise reduction, telephone, bit-crush) and Slices (cut marks, also with M, and saving the parts between them as separate files). With nothing selected an edit changes the whole sound. To move a part, select it and drag the bar along its top. Ctrl+Z and Ctrl+Shift+Z undo and redo, even after a reload; nothing changes in the project until Save (Ctrl+S; the old file goes to the trash) or Save as. On a phone the toolbar scrolls sideways and Save as is under ⋯.
  • The agent and sounds: the audio tool server gives the agent the same editing: it can measure a sound (length, levels, where the silences are), look at its waveform as a picture, run a list of edits (every edit in the editor, plus putting in a part of another sound) and split it at cut points. A file it replaces goes to the trash. Select a part in the editor and press Ask the agent to tell it which part; a player or editor that is open picks up its changes within a few seconds.
  • Video editor: a video file opens as a player; Edit opens its timeline, or starts one with it as the first clip. The Timeline view (the film icon) lists the project's timelines. A .timeline.json opens as the editor, laid out like the wave editor: the player with the inspector beside it (below on a phone), play controls, and the tracks (Video, Titles, Sound) with a playhead you can click or drag on the ruler. Drag a block to move it and its right edge to change the length; S splits at the playhead, Ctrl+D duplicates, Delete removes, Ctrl+Z and Ctrl+Shift+Z undo and redo, and the zoom buttons or + and − zoom the tracks. The menus add titles, colour cards and media, move clips, and set the video's size, frame rate and sound. The inspector changes timing, fit, colour, the transition from the previous clip (58 kinds in groups: fades, wipes, slides, shapes, slices and wind) and effects (26, grouped as Colour, Look, Motion and Fades; tap a chip to turn one on, and its setting is a slider). The Effects and Transition menus in the toolbar do the same for the selected clip, or the one under the playhead. A note says when the player shows an older render; Preview renders a quick small one and Render the full video. Select a part and press Ask the agent to point it at that part.
  • The agent can make short clips with generate_video (about two minutes per second of video at 1280×704).
  • Voices: the Voices view (the microphone in the activity bar) reads text aloud in a shared cast of voices, in Greek and 29 other languages, as MP3 or WAV to play, download or save into the project. A delivery hint such as "slower, cheerful" changes how it reads. The cast has Greek and English voices (Ελληνικά and English in the voice menu, with chips to show one language); a voice reads any language, but sounds most natural in its own. A new voice gets a language and a sample sentence in it.
  • Make a new voice with +: describe it ("a warm woman in her forties, calm, slow"), listen to three takes and keep one. The kept take makes the voice sound the same every time.
  • Or copy a voice from a recording with the microphone button: choose a sound in the open folder (3 to 15 seconds of one person speaking clearly is best, at most 30; give a start and end to use only part of it), type the words spoken in it for a much closer copy, say whose voice it is and why it may be copied (your own voice, a voice made by a machine that you may reuse, or the speaker's written permission), make a test reading and keep it. Never copy a public figure or another service's voice library. The recording itself becomes the voice; a voice with its words reads in the recording's own delivery unless you give another. The agent can do the same with save_voice, or read once in a recording's voice with speak.
  • The agent uses the same voices through its voice tools: "read the introduction in the narrator's voice into voice/intro.mp3". Reading takes about three times as long as the speech.

Sharing Studio with others

  • Each person has their own account, folders, chats, skills and tasks.
  • Account & settings (the person icon in the top bar) has a menu on its left. Profile & security: your display name, password, and the browsers you are signed in on, each with its own Sign out. My computers: folders on your own computer. Preferences: theme and notifications. Models: which models the picker in the top bar shows, by group (All, None) or one by one, saved for your account in every browser; Choose models… at the end of the picker opens it, and a hidden model still answers /model. For admins, its Model server box says which server Studio talks to and lists the others running on this machine (Ollama, llama.cpp, vLLM, LM Studio, the Strata gateway), each with Use this; Another address takes any address and a key, with Test and Save. The change works at once, without a restart, and the welcome screen offers it when no model server answers. Rename beside a model gives it the name everyone sees. Studio can also talk to Strata's own server (port 8080, or 18080 behind a Strata gateway) on its own: Strata loads the model on the first message, the chat shows the loading bar, the dashboard reads the card and memory from Strata, a long chat is saved and restored around unloads, and Studio unloads the model after 15 minutes without requests (strata_idle_minutes). With strata_dir set to a Strata folder, Studio also starts Strata itself: every profile is a model in the picker, the first message starts its server, choosing another profile switches it once no other run uses Strata, and Graphics card changes how much memory Strata leaves for the tools at its next start. Studio never edits Strata's own profiles.
  • Graphics card (admins, and people an admin gave the Graphics card right): Strata first gives the model the whole card, so it answers faster, and a picture or a reading first unloads it for a moment (it loads again on its next request, about 30 to 90 seconds). Tools ready keeps 9 GB free, so pictures and voices start at once, while the model runs slower all the time. A change takes effect the next time Strata starts: after it unloads when idle, or at once with Restart Strata now (not while an agent run is working).
  • listmonk: with the listmonk tool servers on, the agent works with your listmonk (listmonk.app): it looks at lists and campaigns, imports contacts from a CSV in the project, adds and updates contacts, keeps contact tags and fills a list from a tag so a campaign can go to it, drafts and copies campaigns and saves a preview to look at. Sending (a test, starting, scheduling, pausing or cancelling a campaign, a single email) and deleting contacts (the card shows how many; the database is saved first when a backup command is set) are a separate server, listmonk-send, that always asks first, and the card says how many people a campaign will reach. An admin turns them on with a listmonk API user. Before an import, the CSV is checked (columns email, name and attributes as JSON, valid addresses), so a wrong file is refused with the fix instead of upsetting listmonk; an import that stops moving is called stuck, and the agent can stop it or, with your approval each time, restart listmonk.
  • The agent's web browser: with the browser tool server, the agent opens public websites, reads them, clicks, types and fills forms in a real Chromium, with no saved sign-ins and no way into this machine or its network. A Browser tab shows that browser live (it opens by itself, and from the globe menu in the Explorer). Press Take over to click and type yourself, for example to sign in or get past a check; the agent waits until you press Hand back. The agent is told which page the browser shows, so you can browse there yourself and ask about “this page”; Ask about this page starts such a message. On a phone, Take over shows the page at the phone's width (the agent gets its own size back when you hand back): tap to click, swipe to scroll, and the keyboard button types. When the agent checks a site this project serves (view_page), it opens it in this same browser, so you watch that check live too: the page loading, the clicks and keys, and the phone width. On a computer the page fills the tab, and the button with the screen or phone beside the tabs list switches between the desktop view and a phone view (390 wide, with touch and the phone layout); while the agent checks a page, the check's own size wins.
  • Each tool server has its own icon and colour in the chat (listmonk an envelope in cyan, sending in red, ComfyUI a picture in pink, Blender a cube, the web search a magnifier…), on the left edge of its calls and on its approval cards, so you can see at a glance which one the agent uses.
  • Some tool servers need a program running, such as Blender for the Blender tools. Studio starts it by itself, on the server's screen or invisibly (an admin chooses), the first time the agent needs it; admins see whether it runs, with Start and Stop, under Tool servers.
  • Tools & setup (admins, in Account & settings): installs the tools Studio uses on a new machine, and local models. Local models lists PolyStrata (Qwen3.6-35B-A3B, fast; Ornith 1.5 122B, the strongest at keeping a long chat's rules) and Strata (Swift 1.5): pick a model that fits from the list and press Install, or Add this model once one is installed. Their own setup builds the engine for the card (AMD or NVIDIA) and downloads the model, with its progress on the page; then the model is in the picker, and the first message to it starts its server, with nothing else needed. It shows the machine (system, memory, free disk, graphics card and whether ROCm can use it, Docker, Node.js, Python) and every tool with its state: Installed, Can install, Needs something first, or Won’t fit here. Install everything this machine can run installs all that fit, or tick the ones you want and press Install chosen; it runs in the background, and each tool ends with a check and its tool server added to Tool servers. Studio does not use sudo, so what needs root (system packages, the docker and graphics groups) comes as one script, studio-setup.sh, to download and run once with sudo bash studio-setup.sh, then Check again. On a new machine, start with ./install.sh in Studio's folder. The engines on the graphics card need an AMD card that ROCm supports: ComfyUI with Z-Image Turbo, ACE-Step music, voices and sound effects are part of everything; more picture models, Qwen-Image, Wan video clips, ACE-Step XL and HeartMuLa are marked Optional, so you choose them. Codex (OpenAI) installs OpenAI's Codex CLI and turns Codex on in Studio; sign in once in a terminal with codex login --device-auth. Updates lists it too: a new Codex version brings new models to the picker. Each row says how large a card it needs and how much it downloads; downloads show their progress, resume after a stop, and are checked against their checksums. After the script adds you to a group, restart the computer before installing.
  • Updates (admins, in Account & settings): every third-party tool Studio uses, grouped (Docker services, tool servers and engines, programs and web libraries, system packages), with what is installed and what is new. Update installs it, tests it and rolls back by itself if the test fails; Roll back goes back to the version before. At night (03:00–05:00 unless you change it), when nothing is working, the safe ones update by themselves: Docker images that change no database, and the npm tool servers. ComfyUI, the voice and sound engines, Strata and PolyStrata (updated through their own setup, which rebuilds the engine; the earlier engine stays for Roll back), Blender, Playwright and the web libraries wait for a click. System packages show the sudo command to run yourself. A dot on the account button says something is new.
  • Admins also see Users (invite links, find a person, each person's rights as switches: Own computer and Graphics card, which lets them choose how the card is shared, and a ⋯ menu for reset links, roles, disabling and deleting, with each person's last sign-in), Tool servers and Backups.
  • One model serves everyone, so one person uses the agent at a time. The waiting room (people icon) shows who has it and your place in line; your turn comes with a notice. Editing files and terminals never wait.
  • The waiting room has three tabs. Line: one list, starting with who has the agent now (working or between runs, for how long), then everyone waiting with about when their turn comes; your row has Leave, or Take my turn when it is yours, and Join line shows the place and wait you would get. Admins move or remove people from the ⋯ on their row. The rules fold away under How turns work. Chat: a conversation for everyone and one private conversation per person, each with its own unread count; it never goes to the model. People: everyone online and what they are doing, with Message and Pass a chat.
  • The people icon carries two badges: new messages and chats passed to you at the top, how many have or wait for the agent at the bottom. The tab title shows unread messages and your place, such as "(2) #3".
  • Alerts: you hear when someone joins or leaves the line, and when the window is in the background you get a desktop notification (and a sound, if you choose) for your turn, private messages and chats passed to you. Choose in the Line tab.
  • Passing a chat: from People, or the send icon beside a chat in the chats menu, pick the chat, the person and a note. They get a card to accept or decline; accepting copies the chat and its folder into their own space and opens it there, so both of you carry on separately. You hear their answer.

Shared projects

The Share button (the people icon beside the folder's name in the top bar) shares the open folder with other people here. They work on the same files, not copies, and in the same sandbox. Each person gets switches: Change files, Run the agent, Terminal, Delete and Manage people; Co-owner turns them all on. Without a switch a person can still look. The top bar says shared with 2 or shared by sara, and Open folder lists such folders under Shared with me. Chats stay private: the people icon in the chat list shares one with everyone who has the folder, who can then read it and carry it on. One agent works in a folder at a time. A folder on someone's computer can be shared too: what others run there runs on that computer. In a server folder whose Sandbox is off, people who are not admins can change files but cannot run the agent or a terminal. Anyone can leave a folder shared with them from the Share window.

A folder on your own computer

Where a folder lives shows by its icon, in the top bar beside its name and in Open folder: on the server (your space in Studio), on your computer (green when connected, grey when its helper is off), a kept copy (amber: Studio's copy of a computer folder that was disconnected) or passed to you (violet: a copy someone passed you). Open folder has four tabs (Your space, Shared with me, Recent, My computers) in a window that never needs scrolling as a whole; Your space shows Your space › folder instead of server paths, and a row goes into a folder while its Open opens it.

Studio keeps a copy of each connected folder on the server and keeps both in step: the agent edits the copy, commands run on your computer. Disconnect in Studio asks whether to keep that copy or delete it; Disconnect in the helper (0.07 or newer) tells Studio, which keeps the copy under Copies kept from disconnected computers in My computers, with Delete copy. A deleted copy can be brought back by an admin for 30 days.

If an admin allows it for your account, a folder on your own Windows or Linux computer can be worked on in Studio, with that computer's own programs.

  1. Choose Open folder → Connect a folder on my computer. Studio shows a pairing code and the helper to download. New code makes a fresh one if it expired; the old one then stops working.
  2. The window has three steps side by side: Download (for the system picked above, Windows or Linux), Start it and Pair with this code. Its last line says when the helper has connected.
  3. A computer with an older helper shows Update to 0.07 in My computers. Press it for the update window: download the new helper and start it; it makes the running old one quit and takes over its folders, with no code. The window says when every folder of that computer runs the new version.
  4. My computers lists your folders under each computer. Rename beside a computer gives it your own name (DESKTOP-K6F5SDF → DEV PC), shown everywhere in Studio, including folder names (test1@DEV PC). Only the display changes; the folder's path stays the same. Leave the name empty to go back.
  5. On your computer, start the helper (studio-helper.exe on Windows, studio-helper on Linux). It starts quietly, with an icon in the tray by the clock, and the first time it opens its window (on Linux, a page in your browser). Fill in Studio's address, the code and the folder (Browse… picks it), then Connect.
  6. The folder opens in Studio with a computer icon beside its name, green while the helper is connected.
  • Studio keeps a copy of the folder in sync. Your edits and the agent's reach the computer within seconds; commands, tests and terminals run there, in PowerShell on Windows and bash on Linux, and what they change comes back before the agent continues.
  • Folders such as node_modules, .venv and target stay on the computer, as do files over 25 MB.
  • If the same file changes in both places at once, the computer's version is kept and Studio's goes to .strata-studio/conflicts.
  • After the first folder, the helper starts by itself when you sign in to the computer (switch it off in its page or its tray menu). At sign-in it starts quietly, with no window. Its tray icon is green while every folder is connected; the menu opens its window, connects another folder or quits. Starting the helper again also opens its window. When it is not running, you can still read and edit the copy in Studio; commands wait for it to come back.
  • Servers the project starts run on that computer, so the Live tab cannot show them.
  • A web server that the agent, a command or a Studio terminal starts on your computer shows in Studio too: the globe button in the Explorer lists it and opens it in a Live tab, and the agent can look at it with view_page. The helper makes each request on your computer and sends the answer back. Programs you started yourself outside Studio are never reachable. This needs helper 0.06 or later.
  • To stop sharing, choose Disconnect under My computers. The copy in Studio stays, as an ordinary folder.

Phones and tablets

On a phone, tabs at the bottom switch between Files, Editor, Chat and Terminal, and the top-bar controls are in the More sheet. A file's actions are behind the menu button on its row. On a tablet the file list opens over the editor, with the chat beside it.

In the terminal, swipe to scroll; a quick swipe keeps gliding. The wrap button at the top right of the terminal chooses how long lines show: on, they wrap at the screen's edge; off, they stay on one line and you swipe sideways (or scroll sideways with a mouse) to read them. To copy, select with the mouse, or on a phone hold a finger on a word and drag; a bar offers Copy and Select all. Ctrl+Shift+C copies too, and Ctrl+C copies while text is selected (otherwise it stops the running command).

When something goes wrong

  • "Studio was updated": press Reload to get the newest page.
  • Nothing happens after sending: the model may be loading (watch the bar), or someone else has the agent (see the waiting room).
  • The run stopped: the line at the end says why: turn limit, cut-off reply, going in circles, errors. Continue usually helps; for model errors, check that your model server (Ollama, llama.cpp, vLLM, LM Studio or the Strata gateway) is running.
  • The answer is in the wrong language: write your message in the language you want; Studio tells the model. A final reply in English to a Greek chat is sent back once. With Strata models, Chinese, Japanese, Korean, Cyrillic, Arabic, Hebrew, Indic, Thai and Vietnamese characters cannot be written at all unless you ask for one of those languages or the chat already holds them. A word mixing Greek and Latin letters («αρχείa») is repaired when the Greek word it meant is clear; other mixed replies are sent back once, and a mixed word left after that is removed.
  • Admins: the model gauges (top bar) show memory, speed and pressure, and Loaded now lists what holds the graphics card and RAM at this moment: the language model, ComfyUI, the voice and sound engines, Blender and anything else large, each with its VRAM and RAM.

Τα πρώτα βήματα

Το Eidoloom Studio είναι ένα περιβάλλον εκτέλεσης για πράκτορες τεχνητής νοημοσύνης (agent harness), με έναν επεξεργαστή κώδικα γύρω του, μέσα στον browser: ό,τι κάνει ένα μοντέλο πράκτορα (ο κύκλος που σχεδιάζει και καλεί εργαλεία, τα εργαλεία, οι εγκρίσεις και η αναίρεση), με το μοντέλο της επιλογής σας. Ο βοηθός διαβάζει το έργο σας, αλλάζει αρχεία και εκτελεί εντολές, αλλά εσείς έχετε τον έλεγχο: από προεπιλογή ρωτά πριν από κάθε αλλαγή.

  1. Ανοίξτε έναν φάκελο με το κουμπί πάνω αριστερά. Ό,τι κάνει ο βοηθός γίνεται μέσα σε αυτόν τον φάκελο.
  2. Διαλέξτε μοντέλο στην πάνω μπάρα: ένα που τα πάει καλά με τις κλήσεις εργαλείων, όπως το Qwen 3 ή ένα μοντέλο Strata. Το πρώτο μήνυμα μπορεί να φορτώσει το μοντέλο. Μια μπάρα δείχνει την πρόοδο.
  3. Γράψτε τι θέλετε στο πλαίσιο συνομιλίας δεξιά και πατήστε Enter. Με Shift+Enter αλλάζετε γραμμή.

Αριστερά είναι η λίστα αρχείων (Explorer), στη μέση ο επεξεργαστής, από κάτω τα τερματικά και δεξιά η συνομιλία. Τα εικονίδια τέρμα αριστερά αλλάζουν την πλαϊνή στήλη: Explorer, Αναζήτηση, Έλεγχος εκδόσεων, Δεξιότητες, Βίντεο και Εργασίες.

Sandbox. Ο διακόπτης Sandbox στην πάνω μπάρα εκτελεί τις εντολές του βοηθού σε ξεχωριστό container για αυτόν τον φάκελο, ώστε να μην αγγίζουν τον υπόλοιπο υπολογιστή. Οι αλλαγές στα αρχεία γίνονται κανονικά στον φάκελό σας. Οι λογαριασμοί που δεν είναι διαχειριστές δουλεύουν πάντα σε sandbox.

Δουλεύοντας με τον βοηθό

Εγκρίσεις

  • Οι αλλαγές σε αρχεία εμφανίζονται σε κάρτα με τη διαφορά: Accept (αποδοχή), Reject (απόρριψη) ή Choose parts για να δεχτείτε μόνο κάποια από τα σημεία που αλλάζουν. Μια αλλαγή που απορρίψατε δεν εμφανίζεται ξανά στην ίδια εργασία αν διαφέρει μόνο στα σχόλια, στη θέση της ή σε ένα όνομα: ο βοηθός καλείται να σας ρωτήσει ή να δοκιμάσει κάτι άλλο. Μια επόμενη αλλαγή που περιέχει την απορριφθείσα μαζί με άλλα το λέει στην κάρτα της, και μια εντολή που αναφέρει εκείνο το αρχείο σας ρωτά ακόμη και με την αυτόματη εκτέλεση, ώστε μια αλλαγή που απορρίψατε να μη γίνεται ποτέ χωρίς το ναι σας.
  • Οι εντολές δείχνουν ακριβώς τι θα εκτελεστεί: Run ή Skip.
  • Τα Auto-apply edits και Auto-run commands στην πάνω μπάρα σταματούν τις ερωτήσεις. Ενεργοποιήστε τα όταν εμπιστεύεστε την εργασία.
  • Κάθε αλλαγή έχει Undo. Τα αρχεία που διαγράφονται πηγαίνουν στον κάδο, στο .strata-studio/trash.

Ενώ δουλεύει

  • Καθοδήγηση (Steer): γράψτε και πατήστε Enter ενώ ο βοηθός δουλεύει. Θα διαβάσει το μήνυμά σας στο επόμενο βήμα του. Αυτά τα μηνύματα σημειώνονται ως «Steer».
  • Αναμονή: με Alt+Enter ή το κουμπί λίστας, το μήνυμα κρατιέται για όταν τελειώσει η εργασία.
  • Διακοπή με το τετράγωνο κουμπί. Αν κλείσετε τον browser η εργασία δεν σταματά: ανοίξτε ξανά το Studio και θα τη δείτε να συνεχίζει.
  • Η κάρτα σχεδίου δείχνει τη λίστα βημάτων του βοηθού, και η γραμμή πάνω από το πλαίσιο λέει σε ποιο βήμα βρίσκεται.
  • Όταν χρειάζεται μια απόφαση, ο βοηθός μπορεί να κάνει ερωτήσεις με επιλογές: διαλέξτε μία, περισσότερες όπου επιτρέπεται, ή γράψτε τη δική σας απάντηση. Όταν είναι πολλές, εμφανίζονται μία μία: σύρετε ή πατήστε Back και Next. Με Skip αποφασίζει μόνος του.

Πληροφορίες για τον βοηθό

  • Οποιοδήποτε αρχείο: επικόλληση, σύρσιμο ή Add files (ο συνδετήρας). Το ▾ δίπλα του προσθέτει και αρχείο του έργου (αναζήτηση με το όνομα) ή έναν από τους πιο πρόσφατους ήχους, εικόνες και βίντεο. Οι εικόνες φαίνονται στο μοντέλο (πρέπει να βλέπει εικόνες· τα μοντέλα Strata βλέπουν). Τα έγγραφα και τα αρχεία κειμένου διαβάζονται μέσα στο μήνυμα. Κάθε άλλο αρχείο, όπως ήχος, βίντεο, τρισδιάστατο μοντέλο ή συμπιεσμένο αρχείο, αποθηκεύεται στον φάκελο attachments/ του έργου, και ο βοηθός παίρνει τη διαδρομή του, την πλήρη διαδρομή για τα εργαλεία, και λίγα στοιχεία, όπως τη διάρκεια και τη συχνότητα δειγματοληψίας ενός ήχου.
  • Επιλογή και μετακίνηση αρχείων: ένα κλικ σε αρχείο στον Explorer το επιλέγει· διπλό κλικ το ανοίγει (σε κινητό ή tablet ανοίγει με ένα πάτημα). Το Ctrl+κλικ (Cmd σε Mac) προσθέτει ή αφαιρεί μια γραμμή, το Shift+κλικ επιλέγει όλες τις γραμμές ενδιάμεσα, και το Ctrl+A στον Explorer επιλέγει όσες φαίνονται. Σύρετε τις επιλεγμένες γραμμές πάνω σε έναν φάκελο για να μετακινηθούν εκεί, ή σε κενό σημείο για την κορυφή. Αν ένα όνομα υπάρχει ήδη, το Studio ρωτά: Replace, Keep both ή Skip these. Το μενού του δεξιού κλικ και το πλήκτρο Delete ισχύουν για όλες τις επιλεγμένες γραμμές.
  • Εύρεση στον Explorer: ο μεγεθυντικός φακός πάνω στον Explorer, ή το Ctrl+Alt+F (ή το Ctrl+F όταν ο Explorer έχει την εστίαση), ανοίγει μια γραμμή εύρεσης. Ψάχνει ταυτόχρονα ονόματα φακέλων και αρχείων και κείμενο μέσα στα αρχεία: πρώτα τα ονόματα, μετά οι γραμμές που περιέχουν το κείμενο. Με κάθετο ψάχνει ολόκληρες διαδρομές (sounds/int). Κλικ σε φάκελο τον δείχνει στο δέντρο, σε αρχείο ή γραμμή το ανοίγει· δουλεύουν και τα ↑ ↓ και Enter, το Esc την κλείνει. Το Aa ταιριάζει πεζά-κεφαλαία.
  • Λήψη στον υπολογιστή σας: το κουμπί λήψης πάνω στον Explorer κατεβάζει ό,τι επιλέξατε: ένα αρχείο όπως είναι, έναν φάκελο ή πολλά μαζί σε ένα zip, ή, χωρίς επιλογή, όλο το έργο σε zip (χωρίς node_modules, .git, εικονικά περιβάλλοντα και τα σκουπίδια). Και το μενού του δεξιού κλικ έχει Download. Κάθε ήχος, βίντεο, εικόνα, τρισδιάστατο μοντέλο, PDF, πίνακας και αρχείο Markdown έχει κουμπί Download εκεί που ανοίγει, και η προβολή Media έχει ένα για κάθε αρχείο και το Download all για όσα φαίνονται.
  • Αρχεία στον φάκελο: σύρετε αρχεία ή ολόκληρους φακέλους από τον υπολογιστή σας στον Explorer: πάνω σε έναν φάκελο για να μπουν εκεί, ή σε κενό σημείο για την κορυφή. Το κουμπί μεταφόρτωσης του Explorer και το Upload files… στο μενού του δεξιού κλικ κάνουν το ίδιο. Τα μεγάλα αρχεία στέλνονται σε κομμάτια, με μπάρα προόδου. Αν το όνομα υπάρχει ήδη, το Studio ρωτά: Replace (το παλιό πηγαίνει στα σκουπίδια) ή Keep both (κρατά και τα δύο).
  • Word, Excel και άλλα έγγραφα: το Add files (ή επικόλληση, σύρσιμο) δέχεται αρχεία .docx, .xlsx, .pptx και OpenDocument, έως 25 MB. Ο βοηθός παίρνει το κείμενό τους: επικεφαλίδες, παραγράφους, και πίνακες και κάθε φύλλο ως πίνακα (οι τύποι με την τιμή τους). Τα PDF και τα παλιά .doc, .xls, .ppt και .rtf λειτουργούν για διαχειριστές, γιατί τα ανοίγει ένα πρόγραμμα στον server. Έγγραφα του φακέλου αναφέρονται με @, και ο βοηθός τα διαβάζει και μόνος του. Ένα αρχείο πολύ μεγάλο για τη συνομιλία (πάνω από περίπου 200K χαρακτήρες κειμένου, ή φύλλο με πάνω από 3.000 γραμμές) δεν απορρίπτεται: το Studio το αποθηκεύει στον φάκελο attachments/ του έργου, κάθε φύλλο Excel και ως αρχείο CSV με όλες τις γραμμές, και ο βοηθός παίρνει την αρχή και διαβάζει τα υπόλοιπα από εκεί. Το μήνυμά σας δείχνει πού αποθηκεύτηκε.
  • Νέα αρχεία Word και Excel: ζητήστε από τον βοηθό μια αναφορά, μια επιστολή ή ένα υπολογιστικό φύλλο και γράφει ένα πραγματικό αρχείο .docx ή .xlsx στον φάκελο, με επικεφαλίδες, λίστες, πίνακες, έντονη γραμμή επικεφαλίδων και τύπους που υπολογίζονται. Το εγκρίνετε όπως μια αλλαγή, βλέποντας το κείμενό του· αν αντικαθιστά αρχείο, το παλιό πάει στον κάδο, και η Αναίρεση αφαιρεί το νέο.
  • Το @αρχείο αναφέρει ένα αρχείο του φακέλου, ώστε να το διαβάσει ο βοηθός.
  • Το !εντολή εκτελεί μια εντολή από εσάς (π.χ. !make test). Ο βοηθός βλέπει το αποτέλεσμα με το επόμενο μήνυμά σας.
  • Παράθεση: επιλέξτε κείμενο σε μια απάντηση και πατήστε το κουμπί Quote που εμφανίζεται.

Τα μηνύματά σας

Περάστε το ποντίκι πάνω από ένα μήνυμα που στείλατε:

  • Το Copy αντιγράφει το μήνυμα όπως το γράψατε. Τα κουμπιά εμφανίζονται κάτω από το μήνυμα.
  • Το Rewind to here το αφαιρεί μαζί με ό,τι ακολουθεί, το βάζει πίσω στο πλαίσιο και μπορεί να αναιρέσει και τις αλλαγές του βοηθού στα αρχεία από εκεί και μετά.
  • Το Branch from here ανοίγει νέα συνομιλία με ό,τι υπήρχε πριν από αυτό το μήνυμα.
  • Το Ask again (στο τελευταίο σας μήνυμα) το στέλνει ξανά στη θέση της παλιάς απάντησης.

Μετά από μια εργασία

  • Μια κάρτα δείχνει τα αρχεία που άλλαξαν, μαζί με όσα έγραψαν οι εντολές. Πατήστε για να ανοίξει ένα αρχείο, ή @ για να το αναφέρετε στο επόμενο μήνυμα.
  • Το Studio τρέχει μόνο του τα tests του έργου και δείχνει αν περνούν, δίπλα σε όσα δήλωσε ο βοηθός. Για να ορίσετε την εντολή, γράψτε Test command: … στο STUDIO.md.
  • Οι αναγνώσεις, οι λίστες και οι αναζητήσεις μαζεύονται σε μία ήσυχη γραμμή, π.χ. «Read 3 files, searched once». Πατήστε την για να τις δείτε.
  • Κάθε απάντηση έχει κουμπί αντιγραφής. Οι πίνακες, ο κώδικας και οι μαθηματικοί τύποι εμφανίζονται σωστά.

Το Codex ως βοηθός

  • Οι διαχειριστές μπορούν να διαλέξουν ένα από τα μοντέλα Codex της OpenAI στην επιλογή μοντέλου (ομάδα Codex (ChatGPT)). Το Studio τότε τρέχει το πρόγραμμα Codex που είναι εγκατεστημένο σε αυτό το μηχάνημα, με τον λογαριασμό ChatGPT στον οποίο είναι συνδεδεμένο, και η συνομιλία δουλεύει όπως πάντα: τα λόγια του, οι εντολές που τρέχει, οι αλλαγές του με Undo, το σχέδιό του και η κάρτα αρχείων στο τέλος.
  • Το Codex ρωτά πριν από εντολές που μπορεί να αλλάξουν κάτι και πριν από κάθε αλλαγή αρχείου, με τις γνωστές κάρτες· οι εντολές που μόνο διαβάζουν περνούν. Τα Auto-apply edits και Auto-run commands ισχύουν κι εδώ, και ένα μήνυμα που στέλνετε όσο δουλεύει του φτάνει αμέσως.
  • Δουλεύει σε φακέλους με το Sandbox κλειστό, μέσα στο δικό του sandbox, και κρατά τη δική του συνομιλία, οπότε το /compact, το Time-skip και οι προγραμματισμένες εργασίες μένουν στα μοντέλα του Studio. Μια συνομιλία μπορεί να περάσει στο Codex αργότερα: του λέγεται τι ειπώθηκε πριν.
  • Το Codex χρησιμοποιεί και τους servers εργαλείων του Studio (εικόνες, βίντεο, μουσική, φωνές, ηχητικά εφέ, αρχεία ήχου, Blender, αναζήτηση, φυλλομετρητή, έλεγχο ελληνικών, listmonk): κάθε κλήση εμφανίζεται ως η γνωστή γραμμή εργαλείου, ρωτά πρώτα όπως είναι ρυθμισμένος ο server, και οι εικόνες επιστρέφουν στο Codex για να τις δει. Οι κωδικοί και οι ρυθμίσεις των servers μένουν στο Studio.
  • Αφού το Codex σκέφτεται στους servers της OpenAI, το Studio ξεφορτώνει ένα αδρανές Strata πριν από την πρώτη κλήση του Codex για εικόνα, βίντεο, μουσική, φωνή, ήχο ή Blender, ώστε τα εργαλεία να έχουν όλη την κάρτα γραφικών (όχι όσο άλλη συνομιλία χρησιμοποιεί μοντέλο του Studio). Το Strata ξαναφορτώνει στο επόμενο μήνυμά του, σε περίπου μισό λεπτό.
  • Η ένδειξη Codex στη γραμμή κατάστασης δείχνει πόσο έχει χρησιμοποιηθεί από τα όρια Codex του πακέτου ChatGPT: η συνεδρία (το παράθυρο 5 ωρών) και η εβδομάδα, ως δύο μικρές μπάρες. Πατήστε την για τις μπάρες με ποσοστά και πότε μηδενίζεται η καθεμία· ενημερώνεται όσο δουλεύει το Codex.
  • Όταν είναι επιλεγμένο μοντέλο Codex, μια λωρίδα κάτω από την κεφαλίδα της συνομιλίας δείχνει τη χρήση του Codex: τη συνεδρία των 5 ωρών και την εβδομάδα, η καθεμία με τη μπάρα της και πότε μηδενίζεται. Πατήστε την για λεπτομέρειες. Υπάρχει και στα κινητά, όπου η γραμμή κατάστασης είναι κρυμμένη.
  • Το Account & settings → Codex (διαχειριστές) δείχνει ποιον λογαριασμό OpenAI χρησιμοποιεί το Codex, με τη χρήση του, και έχει Sign out. Για σύνδεση: το With a code δίνει έναν σύνδεσμο και έναν κωδικό μίας χρήσης για οποιονδήποτε υπολογιστή ή κινητό· το With a sign-in link ανοίγει τη σελίδα της OpenAI και μετά επικολλάτε τη διεύθυνση localhost όπου καταλήγει ο φυλλομετρητής· το With an API key χρησιμοποιεί πληρωμένο λογαριασμό OpenAI API (το Studio δεν κρατά το κλειδί). Ο λογαριασμός είναι κοινός για τις συνομιλίες Codex όλων των διαχειριστών.
  • Με επιλεγμένο μοντέλο Codex, το κουμπί Effort στο πλαίσιο μηνύματος ορίζει πόσο σκέφτεται το Codex σε αυτή τη συνομιλία: τα επίπεδα που προσφέρει το μοντέλο (Low έως Ultra· το Ultra αναθέτει και μέρη σε βοηθούς) ή το προεπιλεγμένο του μοντέλου. Το δείχνουν και τα μοντέλα Strata: από None (απάντηση αμέσως) έως Extra high, με προεπιλογή του gateway το Medium.
  • Μνήμη μετά από μια εργασία: όταν τελειώνει η τελευταία εργασία, το Studio ξεφορτώνει τις μηχανές φωνής, ήχων και μουσικής και ζητά από το ComfyUI να αδειάσει τα μοντέλα του, κάνοντας επανεκκίνηση στο ComfyUI αν συνεχίζει να κρατά μνήμη. Το ίδιο το Strata ξεφορτώνεται μετά από λίγο χωρίς δουλειά· ορίστε πόσο στο Account & settings → Graphics card. Ο πίνακας του μοντέλου δείχνει τι ελευθερώθηκε και πότε θα ξεφορτωθεί το Strata.
  • Με μοντέλο Codex, το παράθυρο Goal έχει και Codex allowance: πόσες χιλιάδες νέα tokens μπορεί να χρησιμοποιήσει ο στόχος (όσα γράφει το Codex και όσα διαβάζει εκτός της μνήμης του) και ένα ποσοστό του ορίου 5 ωρών όπου σταματά. Το Codex συχνά κάνει όλο τον στόχο σε έναν μακρύ γύρο, οπότε το Studio τα παρακολουθεί και μέσα στον γύρο: όταν εξαντληθεί ένα, ζητά από το Codex να σταματήσει σε καλό σημείο και να συνοψίσει, και το σταματά αν ξεκινήσει δεύτερη κλήση μετά από αυτό ή συνεχίσει για δύο λεπτά. Ο στόχος τότε παύει· το Resume τα δίνει ξανά. Αφήστε ένα πεδίο κενό για χωρίς όριο.
  • Το Codex μπορεί να αναθέσει μέρη μιας μεγάλης εργασίας σε βοηθούς (sub-agents): ο καθένας εμφανίζεται ως γραμμή με την εργασία και την απάντησή του, και οι εντολές και οι αλλαγές τους ρωτούν και φαίνονται όπως του ίδιου του Codex.
  • Το Codex τρέχει στους servers της OpenAI, άρα ό,τι διαβάζει φεύγει από αυτό το μηχάνημα, και κάθε μήνυμα μετρά στα όρια Codex του πακέτου ChatGPT. Τα τοπικά μοντέλα τα κρατούν όλα εδώ.

Μεγάλες εργασίες

  • Στόχοι: το κουμπί Goal δίπλα στο Plan first ανοίγει ένα παράθυρο: ο στόχος, πώς φαίνεται ότι ολοκληρώθηκε, τι να προσέξει, και έως πόσους γύρους (20 αν δεν το αλλάξετε). Ή γράψτε /goal Να περνούν όλα τα tests. Ο βοηθός δουλεύει σε γύρους, ώσπου να αναφέρει ότι έφτασε τον στόχο, να πει ότι κόλλησε, ή να τελειώσουν οι γύροι. Μια μπάρα πάνω από το πλαίσιο δείχνει τον στόχο, με Pause, Resume, Edit και Clear· το κουμπί δείχνει την κατάστασή του και τον ξανανοίγει για αλλαγές.
  • Πρόοδος: η γραμμή κάτω από τα μηνύματα λέει τι κάνει ο βοηθός αυτή τη στιγμή. Ένα μεγάλο βήμα (απόδοση βίντεο, αφήγηση, εικόνα) δείχνει εκεί τη δική του μπάρα, με το ποσοστό και τον χρόνο που απομένει, και στη γραμμή του μέσα στη συνομιλία. Η ριγέ μπάρα σημαίνει ότι δουλεύει αλλά δεν ξέρει πόσο απέχει από το τέλος. Το πορτοκαλί σημαίνει ότι περιμένει (την κάρτα γραφικών, μια ουρά ή εσάς), όχι ότι δουλεύει. Το ποσοστό φαίνεται και στον τίτλο της καρτέλας του φυλλομετρητή και, στο κινητό, στην καρτέλα Chat. Στο καρφιτσωμένο σχέδιο, ένα βήμα που ο βοηθός προσπέρασε διαγράφεται ως παραλειμμένο, δεν τσεκάρεται.
  • Τερματικό: σύρετε για κύλιση· ένα γρήγορο σύρσιμο συνεχίζει να κυλά. Το κουμπί αναδίπλωσης πάνω δεξιά στο τερματικό ορίζει πώς φαίνονται οι μεγάλες γραμμές: ανοιχτό, αναδιπλώνονται στην άκρη της οθόνης· κλειστό, μένουν σε μία γραμμή και τις διαβάζετε σύροντας προς τα πλάγια (ή με οριζόντια κύλιση του ποντικιού). Για αντιγραφή, επιλέξτε με το ποντίκι ή, στο κινητό, κρατήστε το δάχτυλο σε μια λέξη και σύρετε· μια μπάρα δίνει Αντιγραφή (Copy) και Επιλογή όλων (Select all). Αντιγράφουν και τα Ctrl+Shift+C και Ctrl+C όταν υπάρχει επιλογή (αλλιώς σταματά την εντολή που τρέχει).
  • Μνήμη: ο κύκλος στη γραμμή κατάστασης δείχνει πόσο γεμάτη είναι η μνήμη του μοντέλου για αυτή τη συνομιλία. Το /compact αντικαθιστά τα παλιότερα μηνύματα με μια περίληψη που γράφει το μοντέλο, ώστε να έχει ξανά χώρο. Εσείς βλέπετε ολόκληρη τη συνομιλία. Όταν μια εργασία τελειώνει με τη μνήμη πάνω από 85%, εμφανίζεται το Summarize and continue. Με μοντέλο μικρής μνήμης (μοντέλο Ollama με num_ctx), το Studio συντομεύει την παλιότερη έξοδο εργαλείων καθώς γεμίζει και, κοντά στο όριο, κάνει την περίληψη μέσα στην ίδια την εργασία, κρατώντας το τελευταίο σας αίτημα.
  • Ένα μήνυμα πολύ μεγάλο για τη μνήμη του μοντέλου μπορεί να αποθηκευτεί ως αρχείο, που ο βοηθός διαβάζει κομμάτι κομμάτι, ή να συντομευτεί.
  • Αν ο βοηθός κάνει κύκλους (τις ίδιες αποτυχημένες κινήσεις, το σχέδιο ξανά και ξανά), το Studio τον προειδοποιεί μία φορά και μετά σταματά την εργασία εξηγώντας γιατί. Το Continue συνεχίζει από εκεί που σταμάτησε οποιαδήποτε εργασία.

Εργασίες με πρόγραμμα

Εργασίες (Tasks)

Ανοίξτε τις Εργασίες (το εικονίδιο με το ρολόι αριστερά) και πατήστε +. Μια εργασία στέλνει στον βοηθό ένα μήνυμα κάθε ώρα, μέρα, εργάσιμη, εβδομάδα ή λίγα λεπτά, στον φάκελό της, και κρατά το αποτέλεσμα.

Τι επιτρέπεταιΣημασία
Look onlyPlan first: διαβάζει και αναφέρει, χωρίς να αλλάξει τίποτα.
Stop at what needs a yesΔεν υπάρχει κανείς να εγκρίνει, οπότε οι αλλαγές και οι εντολές που χρειάζονται έγκριση παραλείπονται και αναφέρονται στο αποτέλεσμα.
Do everythingΑλλαγές και εντολές γίνονται χωρίς ερώτηση.

Κάθε εκτέλεση έχει τη δική της συνομιλία (Open the chat στις λεπτομέρειες). Όσες εργασίες χρειάζονται την προσοχή σας παίρνουν σήμα. Οι εκτελέσεις που χάθηκαν όσο το Studio ήταν κλειστό δεν γίνονται αργότερα, και τρεις αποτυχίες στη σειρά βάζουν την εργασία σε παύση. Μια εργασία ξεκινά μόνο όταν ο βοηθός είναι ελεύθερος.

Επαναλήψεις (Loops)

Το /loop 10m έλεγξε αν περνά το build στέλνει ξανά αυτό το μήνυμα στην ίδια συνομιλία κάθε 10 λεπτά. Τελειώνει με φράσεις όπως stop after 3 answers, for 2 hours ή stop when it says passed, ή με /loop stop.

Προσαρμογή

  • Δεξιότητες (Skills): ο βοηθός αποθηκεύει τρόπους δουλειάς που θέλει να ξαναχρησιμοποιήσει, σε όλους τους φακέλους, και τους φορτώνει όταν ταιριάζουν. Μπορείτε να τις διαβάσετε, να τις διορθώσετε και να γράψετε δικές σας στη στήλη Skills, και να τις βρείτε με αναζήτηση, ανά είδος, ανά συχνότητα χρήσης ή ανά φάκελο προέλευσης.
  • Τα δικά σας εργαλεία: στη στήλη Skills, προσθέστε οδηγίες που ο βοηθός μπορεί να διαβάσει (π.χ. τους κανόνες της ομάδας), ή μια εντολή που μπορεί να εκτελέσει, π.χ. ένα script δημοσίευσης. Η εντολή παίρνει ό,τι της δίνει ο βοηθός στο $STUDIO_INPUT και ρωτά πριν τρέξει, όπως κάθε εντολή.
  • Ρυθμίσεις συνομιλίας (το γρανάζι πάνω από τη συνομιλία): πόσο σκέφτεται το μοντέλο σε αυτή τη συνομιλία (reasoning effort), ειδοποίηση ή ήχος όταν μια εργασία τελειώνει ή σας περιμένει ενώ είστε σε άλλη καρτέλα, και υπαγόρευση με κουμπί μικροφώνου.
  • Έλεγχος ελληνικών και γλωσσάρι: ο βοηθός ελέγχει τα ελληνικά με το greek-check: ορθογραφία, και γραμματική όπως συμφωνία άρθρου, επιθέτου και ουσιαστικού («Η κανόνας»), υποκειμένου και ρήματος («Οι ναυτικοί βλέπει»), «θα πήγα», «Που…;» και «?». Τα ευρήματα έρχονται ως Fix these (λάθη), Check these (ίσως σωστά, όπως το τελικό ν) και Notes. Στο Account & settings → Greek ένας διαχειριστής κρατά το γλωσσάρι: όρους προς αποφυγή με αυτό που προτιμάμε και γιατί (σε όλους τους τύπους τους), και ονόματα που είναι σωστά, ώστε να μην τα σημειώνει ο ορθογράφος. Όλοι μπορούν να το δουν και να δοκιμάσουν τον έλεγχο εκεί.
  • Θέματα: Dark, Light και Sepia, από την πάνω μπάρα.
  • Οι ρυθμίσεις, οι συνομιλίες και οι εργασίες σας ακολουθούν στα άλλα παράθυρα και τις άλλες συσκευές σας.
Η υπαγόρευση χρησιμοποιεί την αναγνώριση ομιλίας του browser. Στον Chrome και στον Edge η φωνή σας πηγαίνει στη Google ή στη Microsoft για να γίνει κείμενο, γι' αυτό είναι απενεργοποιημένη μέχρι να την ενεργοποιήσετε.

Προβολή αποτελεσμάτων

  • Καρτέλες: όταν τα ανοιχτά αρχεία δεν χωρούν, εμφανίζεται μια λεπτή μπάρα κύλισης κάτω από τις καρτέλες τους: σύρετέ την, πατήστε πάνω της ή γυρίστε τη ροδέλα πάνω από τις καρτέλες. Σύρετε μια καρτέλα στο πλάι για να τη μετακινήσετε σε άλλη θέση (σε οθόνη αφής, κρατήστε την πρώτα για λίγο)· η σειρά διατηρείται.
  • Προεπισκόπηση: ιστοσελίδες, εικόνες, PDF και βίντεο ανοίγουν μέσα στον επεξεργαστή. Τα αρχεία CSV και TSV ανοίγουν ως πίνακας με ταξινόμηση και αναζήτηση. Τα αρχεία Word, PowerPoint και OpenDocument ανοίγουν ως σελίδες, όπως τυπώνονται, και τα PDF το ίδιο, σε κάθε φυλλομετρητή και στο κινητό: βέλη σελίδας, πεδίο αριθμού σελίδας, Larger, Smaller και Fit (ή Ctrl + ροδέλα), και κείμενο που επιλέγεται και αντιγράφεται. Τα βιβλία εργασίας Excel ανοίγουν ως φύλλα με κελιά, με καρτέλα για κάθε φύλλο, γράμματα στηλών, αριθμούς γραμμών και αναζήτηση (οι τύποι με την τιμή τους)· το Page view τα δείχνει ως τυπωμένες σελίδες και το Sheets επιστρέφει. Τις σελίδες τις φτιάχνει στον server το LibreOffice, αποκομμένο από το δίκτυο και από τα αρχεία του Studio, και κρατιούνται μέχρι να αλλάξει το αρχείο. Το κουμπί του χάρτη κώδικα δίπλα στο κουμπί αναδίπλωσης (ή Alt+M) δείχνει ή κρύβει τον μικρό χάρτη του αρχείου στη δεξιά άκρη του επεξεργαστή· η επιλογή σας σας ακολουθεί και στα άλλα σας παράθυρα. Τα αρχεία Markdown (.md) ανοίγουν ως καθαρό έγγραφο, με επικεφαλίδες, πίνακες, εικόνες του φακέλου και συνδέσμους που ανοίγουν άλλα αρχεία· το Edit δείχνει το κείμενο για αλλαγές και το Preview το ξαναδείχνει ως έγγραφο, μαζί με ό,τι δεν έχει αποθηκευτεί. Το κουμπί Preview/Code εναλλάσσει την προβολή.
  • Ζωντανοί servers: όταν το έργο τρέχει έναν server, το κουμπί με την υδρόγειο στον Explorer τον ανοίγει σε καρτέλα Live μέσα στο Studio. Μπορεί να τον ανοίξει και ο βοηθός για εσάς, και να τον δει ο ίδιος, σε οθόνη υπολογιστή ή όπως σε κινητό, δείχνοντάς σας μια εικόνα από αυτό που είδε.
  • Οι εικόνες της συνομιλίας ανοίγουν σε καρτέλα εικόνας με μεγέθυνση, λήψη και αντιγραφή. Το ίδιο και τα αρχεία εικόνων του έργου (και οι υφές): μεγέθυνση με τη ροδέλα, με τσίμπημα δύο δαχτύλων ή με + και −, μετακίνηση με σύρσιμο, διπλό κλικ για προσαρμογή.

Εικόνες, βίντεο και φωνές

  • Με τον server εργαλείων ComfyUI, ο βοηθός φτιάχνει εικόνες (Z-Image, SDXL, Qwen-Image), βίντεο και μουσική. Η ένδειξη ComfyUI στη γραμμή κατάστασης (και το κουμπί με το αστεράκι σε πλαίσιο στην πάνω γραμμή) ανοίγει έναν πίνακα με ό,τι φτιάχνεται, την ουρά και τα προεπιλεγμένα μοντέλα εικόνας και μουσικής. Το κουμπί με τα επίπεδα δείχνει τη ροή εργασίας ως κόμβους.
  • Μουσική και ηχητικά εφέ: ο βοηθός φτιάχνει μουσική με το generate_music (ACE-Step 1.5: τραγούδια με στίχους σε 50 γλώσσες, και ελληνικά, ή ορχηστρικά, έως 10 λεπτά· η ποιότητα best χρησιμοποιεί το μεγαλύτερο μοντέλο και όλη την κάρτα γραφικών) ή HeartMuLa 3B (ακολουθεί πιστά τους στίχους, έως 4 λεπτά, πιο αργό)· η επιλογή Μουσική στο πάνελ του ComfyUI ορίζει ποιο χρησιμοποιεί ο βοηθός, εκτός αν ζητήσετε κάποιο, και ηχητικά εφέ με το make_sound (MOSS-SoundEffect: φύση, πόλη, ζώα, αντικείμενα, έως 30 δευτερόλεπτα). Και τα δύο αποθηκεύουν αρχεία MP3 στο έργο σας, έτοιμα για ένα χρονολόγιο βίντεο, και δείχνουν μπάρα προόδου όσο δουλεύουν.
  • Τα μεγάλα μοντέλα (Qwen-Image, βίντεο) ξεφορτώνουν το μοντέλο συνομιλίας όσο δουλεύουν, κάτι που προσθέτει λίγα λεπτά.
  • Πολυμέσα: η στήλη Media (το εικονίδιο με τα πλαίσια και το σύμβολο αναπαραγωγής) δείχνει όλους τους ήχους, τη μουσική, τις εικόνες, τα βίντεο και τα τρισδιάστατα μοντέλα του έργου, πρώτα τα νεότερα: οι ήχοι παίζουν επί τόπου με τη διάρκειά τους, οι εικόνες και τα τρισδιάστατα μοντέλα φαίνονται ως μικρογραφίες, βίντεο και ήχοι ανοίγουν ως αναπαραγωγή, και το Edit ενός ήχου ανοίγει τον επεξεργαστή κυματομορφής. Τα τρισδιάστατα μοντέλα (GLB, glTF, OBJ, STL, FBX, PLY, και για διαχειριστές αρχεία Blender .blend, που τα εξάγει πρώτα το Blender) ανοίγουν σε προβολή 3D: σύρετε για περιστροφή, ροδέλα ή τσίμπημα για μεγέθυνση, δεξί σύρσιμο για μετακίνηση· δείχνει πλέγματα, τρίγωνα και μέγεθος, με Reset view, Turn, Wireframe, Grid και τις κινήσεις του μοντέλου. Φιλτράρετε ανά είδος, αναζητήστε με όνομα ή ταξινομήστε (νεότερα, παλαιότερα, όνομα Α–Ω ή Ω–Α, μεγαλύτερα, μικρότερα, μακρύτερα, συντομότερα, ή ανά φάκελο· η επιλογή μένει στον φυλλομετρητή)· το Open το ανοίγει στον επεξεργαστή, το Timeline (σε βίντεο φτιαγμένο από χρονολόγιο) ανοίγει το χρονολόγιό του, και το @ το βάζει στο επόμενο μήνυμά σας.
  • Ήχοι: κάθε αρχείο ήχου (MP3, WAV, FLAC, OGG, Opus, M4A) ανοίγει ως αναπαραγωγή με την κυματομορφή του: κλικ ή σύρσιμο πάνω της για να πάτε σε εκείνο το σημείο, Play ή Space, επανάληψη, και ένταση αναπαραγωγής που δεν αλλάζει το αρχείο. Το Edit (και στη στήλη Media) ανοίγει τον επεξεργαστή κυματομορφής· το Done γυρίζει στην αναπαραγωγή και ρωτά πρώτα αν κάτι δεν έχει αποθηκευτεί.
  • Επεξεργαστής κυματομορφής: σύρετε για να επιλέξετε ένα κομμάτι, Shift+κλικ για να το επεκτείνετε, κλικ για να βάλετε τον δρομέα· Ctrl+ροδέλα ή δύο δάχτυλα για μεγέθυνση, και η λωρίδα από πάνω δείχνει όλο τον ήχο και μετακινεί την προβολή. Η γραμμή εργαλείων έχει αναίρεση και επανάληψη, αποκοπή, αντιγραφή, επικόλληση και διαγραφή, και μενού: Edit (μόνο η επιλογή, σίγαση, εισαγωγή σιωπής), Volume (σταδιακή αύξηση και μείωση, πιο δυνατά ή πιο σιγά, κανονικοποίηση στο πιο δυνατό σημείο ή στη συνολική ένταση), Time (ταχύτητα με ή χωρίς αλλαγή τόνου, τόνος, αντιστροφή), Effects (αντήχηση, ηχώ, chorus, flanger, phaser, tremolo, vibrato, low- και high-pass, μπάσα, πρίμα, compressor, μείωση θορύβου, τηλέφωνο, bit-crush) και Slices (σημάδια κοπής, και με το M, και αποθήκευση των κομματιών ανάμεσά τους ως χωριστά αρχεία). Χωρίς επιλογή, η αλλαγή αφορά όλο τον ήχο. Για να μετακινήσετε ένα κομμάτι, επιλέξτε το και σύρετε τη λωρίδα στο πάνω μέρος του. Ctrl+Z και Ctrl+Shift+Z για αναίρεση και επανάληψη, ακόμη και μετά από ανανέωση της σελίδας· τίποτα δεν αλλάζει στο έργο πριν από το Save (Ctrl+S· το παλιό αρχείο πάει στον κάδο) ή το Save as. Στο κινητό η γραμμή εργαλείων κυλά πλάγια και το Save as είναι στο ⋯.
  • Ο βοηθός και οι ήχοι: ο διακομιστής εργαλείων audio δίνει στον βοηθό την ίδια επεξεργασία: μετρά έναν ήχο (διάρκεια, ένταση, πού είναι οι σιωπές), βλέπει την κυματομορφή του ως εικόνα, κάνει μια σειρά από αλλαγές (όλες όσες έχει ο επεξεργαστής, και εισαγωγή κομματιού από άλλον ήχο) και τον κόβει σε κομμάτια. Ένα αρχείο που αντικαθιστά πηγαίνει στον κάδο. Επιλέξτε ένα σημείο στον επεξεργαστή και πατήστε Ask the agent για να του πείτε ποιο· μια αναπαραγωγή ή ένας επεξεργαστής που είναι ανοιχτός δείχνει τις αλλαγές του σε λίγα δευτερόλεπτα.
  • Επεξεργαστής βίντεο: ένα αρχείο βίντεο ανοίγει ως αναπαραγωγή· το Edit ανοίγει το χρονολόγιό του ή ξεκινά ένα με αυτό ως πρώτο κλιπ. Η στήλη Timeline (το εικονίδιο με το φιλμ) δείχνει τα χρονολόγια του έργου. Ένα .timeline.json ανοίγει ως επεξεργαστής, όπως ο επεξεργαστής ήχου: η αναπαραγωγή με τις ιδιότητες δίπλα της (από κάτω στο κινητό), τα κουμπιά αναπαραγωγής και τα κανάλια (Video, Titles, Sound) με δείκτη θέσης που μετακινείτε με κλικ ή σύρσιμο στον χάρακα. Σύρετε ένα κομμάτι για να το μετακινήσετε και τη δεξιά του άκρη για να αλλάξετε τη διάρκεια· το S κόβει στον δείκτη, το Ctrl+D το διπλασιάζει, το Delete το σβήνει, Ctrl+Z και Ctrl+Shift+Z για αναίρεση και επανάληψη, και τα κουμπιά μεγέθυνσης ή τα + και − μεγαλώνουν τα κανάλια. Τα μενού προσθέτουν τίτλους, χρωματιστές κάρτες και πολυμέσα, μετακινούν κλιπ και ορίζουν μέγεθος, καρέ ανά δευτερόλεπτο και ήχο. Οι ιδιότητες αλλάζουν χρόνο, προσαρμογή, χρώμα, μετάβαση από το προηγούμενο κλιπ (58 είδη σε ομάδες: σβησίματα, σκουπίσματα, ολισθήσεις, σχήματα, φέτες και άνεμος) και εφέ (26, σε ομάδες Colour, Look, Motion και Fades· πατήστε ένα για να το ενεργοποιήσετε, και η ρύθμισή του είναι ρυθμιστικό). Τα μενού Effects και Transition της γραμμής εργαλείων κάνουν το ίδιο για το επιλεγμένο κλιπ ή αυτό κάτω από τον δείκτη. Μια σημείωση λέει πότε η αναπαραγωγή δείχνει παλιότερη απόδοση· το Preview κάνει μια γρήγορη μικρή και το Render το πλήρες βίντεο. Επιλέξτε ένα σημείο και πατήστε Ask the agent για να ζητήσετε αλλαγή εκεί.
  • Ο βοηθός μπορεί να φτιάξει μικρά κλιπ με το generate_video (περίπου δύο λεπτά για κάθε δευτερόλεπτο βίντεο σε 1280×704).
  • Φωνές: η στήλη Voices (το μικρόφωνο στη γραμμή δραστηριοτήτων) διαβάζει κείμενο φωναχτά με ένα κοινό καστ φωνών, στα ελληνικά και σε 29 άλλες γλώσσες, σε MP3 ή WAV για ακρόαση, λήψη ή αποθήκευση στο έργο. Μια οδηγία ερμηνείας, όπως «πιο αργά, χαρούμενα», αλλάζει τον τρόπο ανάγνωσης. Το καστ έχει ελληνικές και αγγλικές φωνές (Ελληνικά και English στο μενού φωνών, με κουμπιά για να φαίνεται μία γλώσσα)· κάθε φωνή διαβάζει όλες τις γλώσσες, αλλά ακούγεται πιο φυσικά στη δική της. Μια νέα φωνή παίρνει γλώσσα και δοκιμαστική πρόταση σε αυτήν.
  • Φτιάξτε νέα φωνή με το +: περιγράψτε τη («μια ζεστή γυναικεία φωνή γύρω στα σαράντα, ήρεμη, αργή»), ακούστε τρεις εκδοχές και κρατήστε μία. Η εκδοχή που κρατάτε κάνει τη φωνή να ακούγεται ίδια κάθε φορά.
  • Ή αντιγράψτε μια φωνή από ηχογράφηση με το κουμπί του μικροφώνου: διαλέξτε έναν ήχο στον ανοιχτό φάκελο (καλύτερα 3 έως 15 δευτερόλεπτα ενός ανθρώπου που μιλά καθαρά, το πολύ 30· με αρχή και τέλος χρησιμοποιείται μόνο ένα κομμάτι), γράψτε τα λόγια που ακούγονται για πολύ πιστότερο αντίγραφο, πείτε ποιανού είναι η φωνή και γιατί επιτρέπεται να αντιγραφεί (η δική σας φωνή, φωνή φτιαγμένη από μηχανή που έχετε δικαίωμα να ξαναχρησιμοποιήσετε, ή γραπτή άδεια του ομιλητή), φτιάξτε μια δοκιμαστική ανάγνωση και κρατήστε τη. Ποτέ δημόσια πρόσωπα ή φωνές από βιβλιοθήκες άλλων υπηρεσιών. Η ίδια η ηχογράφηση γίνεται η φωνή. Ο βοηθός κάνει το ίδιο με το save_voice, ή διαβάζει μία φορά με τη φωνή μιας ηχογράφησης με το speak.
  • Ο βοηθός χρησιμοποιεί τις ίδιες φωνές με τα εργαλεία φωνής του: «διάβασε την εισαγωγή με τη φωνή της αφηγήτριας στο voice/intro.mp3». Η ανάγνωση διαρκεί περίπου τρεις φορές όσο η ομιλία.

Κοινή χρήση με άλλους

  • Κάθε άτομο έχει δικό του λογαριασμό, φακέλους, συνομιλίες, δεξιότητες και εργασίες.
  • Το Account & settings (το εικονίδιο του ατόμου στην πάνω μπάρα) έχει ένα μενού στα αριστερά. Profile & security: το όνομα που βλέπουν οι άλλοι, ο κωδικός σας και οι φυλλομετρητές όπου είστε συνδεδεμένοι, ο καθένας με δικό του Sign out. My computers: φάκελοι στον δικό σας υπολογιστή. Preferences: θέμα και ειδοποιήσεις. Models: ποια μοντέλα δείχνει η επιλογή μοντέλου στην πάνω μπάρα, ανά ομάδα (All, None) ή ένα-ένα, αποθηκευμένα για τον λογαριασμό σας σε κάθε φυλλομετρητή· το Choose models… στο τέλος της λίστας το ανοίγει, και ένα κρυμμένο μοντέλο απαντά ακόμη στο /model. Για τους διαχειριστές, το πλαίσιο Model server λέει με ποιον διακομιστή μιλά το Studio και δείχνει τους άλλους που τρέχουν σε αυτό το μηχάνημα (Ollama, llama.cpp, vLLM, LM Studio, Strata gateway), ο καθένας με Use this· το Another address δέχεται οποιαδήποτε διεύθυνση και κλειδί, με Test και Save. Η αλλαγή ισχύει αμέσως, χωρίς επανεκκίνηση, και η αρχική οθόνη την προτείνει όταν δεν απαντά κανένας διακομιστής μοντέλων. Το Rename δίπλα σε ένα μοντέλο του δίνει το όνομα που βλέπουν όλοι. Το Studio μιλά και απευθείας με τον δικό διακομιστή του Strata (θύρα 8080, ή 18080 πίσω από έναν Strata gateway), χωρίς gateway: το Strata φορτώνει το μοντέλο με το πρώτο μήνυμα, η συνομιλία δείχνει τη μπάρα φόρτωσης, ο πίνακας διαβάζει την κάρτα και τη μνήμη από το Strata, μια μεγάλη συνομιλία σώζεται και επανέρχεται γύρω από τις εκφορτώσεις, και το Studio εκφορτώνει το μοντέλο μετά από 15 λεπτά χωρίς αιτήματα (strata_idle_minutes). Με το strata_dir να δείχνει σε έναν φάκελο Strata, το Studio ξεκινά και το ίδιο το Strata: κάθε προφίλ είναι ένα μοντέλο στην επιλογή, το πρώτο μήνυμα ξεκινά τον διακομιστή του, η επιλογή άλλου προφίλ τον αλλάζει όταν δεν το χρησιμοποιεί άλλη εργασία, και το Graphics card ορίζει πόση μνήμη αφήνει το Strata στα εργαλεία στην επόμενη εκκίνησή του. Το Studio δεν αλλάζει ποτέ τα προφίλ του Strata.
  • Graphics card (διαχειριστές, και όσοι έχουν το δικαίωμα Graphics card από διαχειριστή): το Strata first δίνει στο μοντέλο όλη την κάρτα, ώστε να απαντά πιο γρήγορα, και μια εικόνα ή μια ανάγνωση πρώτα το ξεφορτώνει για λίγο (ξαναφορτώνει στο επόμενο αίτημά του, περίπου 30 έως 90 δευτερόλεπτα). Το Tools ready κρατά 9 GB ελεύθερα, ώστε εικόνες και φωνές να ξεκινούν αμέσως, ενώ το μοντέλο τρέχει πιο αργά όλη την ώρα. Μια αλλαγή ισχύει την επόμενη φορά που ξεκινά το Strata: όταν ξεφορτωθεί επειδή έμεινε αδρανές, ή αμέσως με το Restart Strata now (όχι όσο δουλεύει ο βοηθός).
  • listmonk: με τους servers εργαλείων listmonk ανοιχτούς, ο βοηθός δουλεύει με το listmonk σας (listmonk.app): βλέπει λίστες και καμπάνιες, εισάγει επαφές από ένα CSV του έργου, προσθέτει και αλλάζει επαφές, κρατά ετικέτες επαφών και γεμίζει μια λίστα από μια ετικέτα ώστε να σταλεί σε αυτή μια καμπάνια, φτιάχνει και αντιγράφει πρόχειρες καμπάνιες και αποθηκεύει μια προεπισκόπηση. Η αποστολή (δοκιμαστικό, έναρξη, προγραμματισμός, παύση ή ακύρωση καμπάνιας, ένα μεμονωμένο email) και η διαγραφή επαφών (η κάρτα δείχνει πόσες· η βάση αποθηκεύεται πρώτα όταν έχει οριστεί εντολή αντιγράφου) είναι ξεχωριστός server, ο listmonk-send, που ρωτά πάντα πρώτα, και η κάρτα λέει σε πόσους θα φτάσει η καμπάνια. Ένας διαχειριστής τους ενεργοποιεί με έναν API χρήστη του listmonk. Πριν από μια εισαγωγή ελέγχεται το CSV (στήλες email, name και attributes ως JSON, έγκυρες διευθύνσεις), ώστε ένα λάθος αρχείο να απορρίπτεται με τη διόρθωση αντί να μπερδέψει το listmonk· μια εισαγωγή που δεν προχωρά λέγεται κολλημένη, και ο βοηθός μπορεί να τη σταματήσει ή, με την έγκρισή σας κάθε φορά, να επανεκκινήσει το listmonk.
  • Ο φυλλομετρητής του βοηθού: με τον server εργαλείων browser, ο βοηθός ανοίγει δημόσιους ιστότοπους, τους διαβάζει, πατά, πληκτρολογεί και συμπληρώνει φόρμες σε έναν πραγματικό Chromium, χωρίς αποθηκευμένες συνδέσεις και χωρίς πρόσβαση σε αυτό το μηχάνημα ή το δίκτυό του. Μια καρτέλα Browser δείχνει αυτόν τον φυλλομετρητή ζωντανά (ανοίγει μόνη της, και από το μενού με την υδρόγειο στον Explorer). Πατήστε Take over για να πατήσετε και να γράψετε εσείς, για παράδειγμα για να συνδεθείτε ή να περάσετε έναν έλεγχο· ο βοηθός περιμένει μέχρι να πατήσετε Hand back. Ο βοηθός ξέρει ποια σελίδα δείχνει ο φυλλομετρητής, οπότε μπορείτε να πάτε εκεί εσείς και να ρωτήσετε για «αυτή τη σελίδα»· το Ask about this page ξεκινά ένα τέτοιο μήνυμα. Σε κινητό, το Take over δείχνει τη σελίδα στο πλάτος του κινητού (ο βοηθός παίρνει πίσω το δικό του μέγεθος με το Hand back): πατήστε για κλικ, σύρετε για κύλιση, και το κουμπί πληκτρολογίου γράφει. Όταν ο βοηθός ελέγχει έναν ιστότοπο που σερβίρει το έργο (view_page), τον ανοίγει στον ίδιο φυλλομετρητή, οπότε βλέπετε κι αυτόν τον έλεγχο ζωντανά: τη φόρτωση της σελίδας, τα κλικ και τα πλήκτρα, και το πλάτος κινητού. Σε υπολογιστή η σελίδα γεμίζει την καρτέλα, και το κουμπί με την οθόνη ή το κινητό δίπλα στη λίστα καρτελών αλλάζει ανάμεσα στην προβολή υπολογιστή και την προβολή κινητού (πλάτος 390, με αφή και τη διάταξη κινητού)· όσο ο βοηθός ελέγχει μια σελίδα, ισχύει το μέγεθος του ελέγχου.
  • Κάθε server εργαλείων έχει το δικό του εικονίδιο και χρώμα στη συνομιλία (το listmonk φάκελο σε κυανό, η αποστολή κόκκινο, το ComfyUI εικόνα σε ροζ, το Blender κύβο, η αναζήτηση στο web μεγεθυντικό φακό…), στην αριστερή άκρη των κλήσεών του και στις κάρτες έγκρισης, ώστε να φαίνεται αμέσως ποιον χρησιμοποιεί ο βοηθός.
  • Κάποιοι servers εργαλείων χρειάζονται ένα πρόγραμμα ανοιχτό, όπως το Blender για τα εργαλεία του Blender. Το Studio το ξεκινά μόνο του, στην οθόνη του server ή αόρατα (το επιλέγει ένας διαχειριστής), την πρώτη φορά που το χρειαστεί ο βοηθός· οι διαχειριστές βλέπουν στα Tool servers αν τρέχει, με Start και Stop.
  • Tools & setup (διαχειριστές, στο Account & settings): εγκαθιστά τα εργαλεία του Studio σε ένα νέο μηχάνημα, και τοπικά μοντέλα. Τα Local models δείχνουν το PolyStrata (Qwen3.6-35B-A3B, γρήγορο· Ornith 1.5 122B, το καλύτερο στο να τηρεί τους κανόνες μιας μεγάλης συζήτησης) και το Strata (Swift 1.5): διαλέξτε από τη λίστα ένα μοντέλο που χωράει και πατήστε Install, ή Add this model όταν έχει ήδη εγκατασταθεί ένα. Το δικό τους setup χτίζει τη μηχανή για την κάρτα (AMD ή NVIDIA) και κατεβάζει το μοντέλο, με την πρόοδο στη σελίδα· μετά το μοντέλο είναι στη λίστα, και το πρώτο μήνυμα προς αυτό ξεκινά τον server του, χωρίς να χρειάζεται τίποτε άλλο. Δείχνει το μηχάνημα (σύστημα, μνήμη, ελεύθερο δίσκο, κάρτα γραφικών και αν μπορεί να τη χρησιμοποιήσει το ROCm, Docker, Node.js, Python) και κάθε εργαλείο με την κατάστασή του: Installed, Can install, Needs something first ή Won’t fit here. Το Install everything this machine can run εγκαθιστά όσα χωράνε, ή επιλέξτε όσα θέλετε και πατήστε Install chosen· τρέχει στο παρασκήνιο, και κάθε εργαλείο τελειώνει με έλεγχο και με τον server εργαλείων του στα Tool servers. Το Studio δεν χρησιμοποιεί sudo, οπότε ό,τι χρειάζεται root (πακέτα συστήματος, οι ομάδες docker και κάρτας γραφικών) δίνεται ως ένα σενάριο, studio-setup.sh, που το κατεβάζετε και το τρέχετε μία φορά με sudo bash studio-setup.sh, και μετά πατάτε Check again. Σε νέο μηχάνημα ξεκινήστε με ./install.sh στον φάκελο του Studio. Οι μηχανές στην κάρτα γραφικών θέλουν κάρτα AMD που υποστηρίζει το ROCm: το ComfyUI με το Z-Image Turbo, η μουσική ACE-Step, οι φωνές και τα ηχητικά εφέ είναι μέρος του «everything»· περισσότερα μοντέλα εικόνων, το Qwen-Image, τα βίντεο Wan, το ACE-Step XL και το HeartMuLa έχουν την ένδειξη Optional, τα επιλέγετε εσείς. Το Codex (OpenAI) εγκαθιστά το Codex CLI της OpenAI και ενεργοποιεί το Codex στο Studio· συνδεθείτε μία φορά σε ένα τερματικό με codex login --device-auth. Το δείχνουν και οι Updates: μια νέα έκδοση του Codex φέρνει νέα μοντέλα στη λίστα. Κάθε γραμμή λέει πόσο μεγάλη κάρτα χρειάζεται και πόσα κατεβάζει· οι λήψεις δείχνουν την πρόοδό τους, συνεχίζουν μετά από διακοπή και ελέγχονται με τα checksum τους. Αφού το σενάριο σας προσθέσει σε μια ομάδα, κάντε επανεκκίνηση του υπολογιστή πριν την εγκατάσταση.
  • Updates (διαχειριστές, στο Account & settings): κάθε εργαλείο τρίτων που χρησιμοποιεί το Studio, σε ομάδες (υπηρεσίες Docker, servers εργαλείων και μηχανές, προγράμματα και βιβλιοθήκες web, πακέτα συστήματος), με ό,τι είναι εγκατεστημένο και ό,τι νεότερο υπάρχει. Το Update το εγκαθιστά, το δοκιμάζει και επιστρέφει μόνο του στην προηγούμενη έκδοση αν η δοκιμή αποτύχει· το Roll back γυρίζει στην έκδοση πριν. Τη νύχτα (03:00–05:00 αν δεν το αλλάξετε), όταν τίποτα δεν δουλεύει, τα ασφαλή ενημερώνονται μόνα τους: εικόνες Docker που δεν αλλάζουν βάση δεδομένων και οι servers εργαλείων του npm. Το ComfyUI, οι μηχανές φωνής και ήχου, το Strata και το PolyStrata (ενημερώνονται μέσω του δικού τους setup, που ξαναχτίζει τη μηχανή· η προηγούμενη μηχανή μένει για το Roll back), το Blender, το Playwright και οι βιβλιοθήκες web περιμένουν ένα κλικ. Τα πακέτα συστήματος δείχνουν την εντολή sudo για να την τρέξετε εσείς. Μια κουκκίδα στο κουμπί λογαριασμού δείχνει ότι υπάρχει κάτι νέο.
  • Οι διαχειριστές βλέπουν επίσης τα Users (σύνδεσμοι πρόσκλησης, αναζήτηση ατόμου, τα δικαιώματα του καθενός ως διακόπτες: Own computer και Graphics card, που του επιτρέπει να διαλέγει πώς μοιράζεται η κάρτα, και ένα μενού ⋯ για συνδέσμους επαναφοράς, ρόλους, απενεργοποίηση και διαγραφή, με την τελευταία σύνδεση του καθενός), Tool servers και Backups.
  • Ένα μοντέλο εξυπηρετεί όλους, οπότε τον βοηθό τον χρησιμοποιεί ένα άτομο τη φορά. Η αίθουσα αναμονής (εικονίδιο με τα άτομα) δείχνει ποιος τον έχει και τη θέση σας στη σειρά. Όταν έρθει η σειρά σας, ειδοποιείστε. Η επεξεργασία αρχείων και τα τερματικά δεν περιμένουν ποτέ.
  • Η αίθουσα αναμονής έχει τρεις καρτέλες. Σειρά: μία λίστα, πρώτα με αυτόν που έχει τώρα τον βοηθό (αν δουλεύει ή είναι ανάμεσα σε εκτελέσεις, και πόση ώρα), μετά όσους περιμένουν, με περίπου πότε έρχεται η σειρά τους· η δική σας γραμμή έχει Leave, ή Take my turn όταν έρθει η σειρά σας, και το Join line δείχνει τη θέση και την αναμονή που θα είχατε. Οι διαχειριστές μετακινούν ή αφαιρούν άτομα από το ⋯ της γραμμής τους. Οι κανόνες κρύβονται κάτω από το How turns work. Συνομιλία: μία συζήτηση για όλους και μία ιδιωτική για κάθε άτομο, η καθεμία με τα δικά της αδιάβαστα· δεν φτάνει ποτέ στο μοντέλο. Άτομα: όσοι είναι συνδεδεμένοι και τι κάνουν, με Μήνυμα και Μεταβίβαση συνομιλίας.
  • Το εικονίδιο με τα άτομα έχει δύο ενδείξεις: πάνω τα νέα μηνύματα και τις συνομιλίες που σας μεταβιβάστηκαν, κάτω πόσοι έχουν ή περιμένουν τον βοηθό. Ο τίτλος της καρτέλας του φυλλομετρητή δείχνει τα αδιάβαστα και τη θέση σας, π.χ. «(2) #3».
  • Ειδοποιήσεις: μαθαίνετε όταν κάποιος μπαίνει ή βγαίνει από τη σειρά, και όταν το παράθυρο είναι στο παρασκήνιο παίρνετε ειδοποίηση στην επιφάνεια εργασίας (και ήχο, αν το επιλέξετε) για τη σειρά σας, τα ιδιωτικά μηνύματα και τις συνομιλίες που σας μεταβιβάστηκαν. Η επιλογή είναι στην καρτέλα Σειρά.
  • Μεταβίβαση συνομιλίας: από τα Άτομα, ή από το εικονίδιο αποστολής δίπλα σε μια συνομιλία στο μενού των συνομιλιών, διαλέγετε τη συνομιλία, το άτομο και ένα σημείωμα. Εκείνο βλέπει μια κάρτα για να τη δεχτεί ή να την αρνηθεί· αν τη δεχτεί, η συνομιλία και ο φάκελός της αντιγράφονται στον δικό του χώρο και ανοίγουν εκεί, ώστε να συνεχίζετε χωριστά. Μαθαίνετε την απάντησή του.

Κοινόχρηστα έργα

Το κουμπί Share (το εικονίδιο με τους ανθρώπους δίπλα στο όνομα του φακέλου στην πάνω μπάρα) μοιράζεται τον ανοιχτό φάκελο με άλλους εδώ. Δουλεύουν στα ίδια αρχεία, όχι σε αντίγραφα, και στο ίδιο sandbox. Κάθε άτομο έχει διακόπτες: Change files, Run the agent, Terminal, Delete και Manage people· το Co-owner τα ανοίγει όλα. Χωρίς διακόπτη, μπορεί μόνο να βλέπει. Η πάνω μπάρα γράφει shared with 2 ή shared by sara, και το Open folder τους δείχνει στο Shared with me. Οι συνομιλίες μένουν ιδιωτικές: το εικονίδιο στη λίστα συνομιλιών μοιράζεται μία με όλους όσοι έχουν τον φάκελο, που μπορούν να τη διαβάσουν και να τη συνεχίσουν. Ένας βοηθός δουλεύει σε έναν φάκελο κάθε φορά. Μπορεί να μοιραστεί και φάκελος από υπολογιστή κάποιου: ό,τι τρέχουν οι άλλοι εκεί τρέχει σε εκείνον τον υπολογιστή. Σε φάκελο του server με το Sandbox κλειστό, όσοι δεν είναι διαχειριστές αλλάζουν αρχεία αλλά δεν τρέχουν τον βοηθό ή τερματικό. Ο καθένας μπορεί να φύγει από φάκελο που του μοιράστηκαν, από το παράθυρο Share.

Ένας φάκελος στον δικό σας υπολογιστή

Πού βρίσκεται ένας φάκελος φαίνεται από το εικονίδιό του, στην πάνω μπάρα δίπλα στο όνομα και στο Open folder: στον server (ο χώρος σας στο Studio), στον υπολογιστή σας (πράσινο όταν είναι συνδεδεμένος, γκρι όταν ο helper του είναι κλειστός), αντίγραφο που κρατήθηκε (πορτοκαλί: το αντίγραφο του Studio από φάκελο υπολογιστή που αποσυνδέθηκε) ή σας το έδωσαν (μωβ: αντίγραφο που σας πέρασε κάποιος). Το Open folder έχει τέσσερις καρτέλες (Your space, Shared with me, Recent, My computers) σε παράθυρο που δεν χρειάζεται κύλιση ολόκληρο· το Your space δείχνει Your space › φάκελος αντί για διαδρομές του server, και μια γραμμή μπαίνει στον φάκελο ενώ το Open τον ανοίγει.

Το Studio κρατά ένα αντίγραφο κάθε συνδεδεμένου φακέλου στον server και τα κρατά ίδια: ο βοηθός αλλάζει το αντίγραφο, οι εντολές τρέχουν στον υπολογιστή σας. Το Disconnect στο Studio ρωτά αν θα κρατήσει ή θα σβήσει αυτό το αντίγραφο· το Disconnect στον helper (0.07 ή νεότερο) ενημερώνει το Studio, που κρατά το αντίγραφο στα Copies kept from disconnected computers στο My computers, με Delete copy. Ένα σβησμένο αντίγραφο μπορεί να το επαναφέρει διαχειριστής για 30 ημέρες.

Αν το επιτρέψει ένας διαχειριστής για τον λογαριασμό σας, μπορείτε να δουλεύετε στο Studio έναν φάκελο του δικού σας υπολογιστή με Windows ή Linux, με τα δικά του προγράμματα.

  1. Επιλέξτε Open folder → Connect a folder on my computer. Το Studio δείχνει έναν κωδικό σύζευξης και το πρόγραμμα βοηθό για λήψη. Το New code φτιάχνει νέο κωδικό αν έληξε· ο παλιός τότε δεν ισχύει πια.
  2. Το παράθυρο έχει τρία βήματα δίπλα δίπλα: Download (για το σύστημα που διαλέγετε πάνω, Windows ή Linux), Start it και Pair with this code. Η τελευταία γραμμή λέει πότε συνδέθηκε ο βοηθός.
  3. Ένας υπολογιστής με παλιότερο βοηθό δείχνει Update to 0.07 στο My computers. Πατήστε το για το παράθυρο ενημέρωσης: κατεβάστε τον νέο βοηθό και ξεκινήστε τον· κλείνει μόνος του τον παλιό και παίρνει τους φακέλους του, χωρίς κωδικό. Το παράθυρο λέει πότε όλοι οι φάκελοι του υπολογιστή τρέχουν τη νέα έκδοση.
  4. Το My computers δείχνει τους φακέλους κάτω από κάθε υπολογιστή. Το Rename δίπλα σε έναν υπολογιστή του δίνει δικό σας όνομα (DESKTOP-K6F5SDF → DEV PC), που φαίνεται παντού στο Studio, και στα ονόματα φακέλων (test1@DEV PC). Αλλάζει μόνο η εμφάνιση· η διαδρομή του φακέλου μένει ίδια. Αφήστε το κενό για να επιστρέψει.
  5. Στον υπολογιστή σας, ξεκινήστε τον βοηθό (studio-helper.exe στα Windows, studio-helper στο Linux). Ξεκινά αθόρυβα, με ένα εικονίδιο δίπλα στο ρολόι, και την πρώτη φορά ανοίγει το παράθυρό του (στο Linux, μια σελίδα στον φυλλομετρητή). Συμπληρώστε τη διεύθυνση του Studio, τον κωδικό και τον φάκελο (το Browse… τον επιλέγει) και πατήστε Connect.
  6. Ο φάκελος ανοίγει στο Studio με ένα εικονίδιο υπολογιστή δίπλα στο όνομά του, πράσινο όσο ο βοηθός είναι συνδεδεμένος.
  • Το Studio κρατά ένα αντίγραφο του φακέλου συγχρονισμένο. Οι δικές σας αλλαγές και του βοηθού φτάνουν στον υπολογιστή μέσα σε λίγα δευτερόλεπτα· οι εντολές, τα τεστ και τα τερματικά τρέχουν εκεί, σε PowerShell στα Windows και σε bash στο Linux, και ό,τι αλλάζουν επιστρέφει πριν συνεχίσει ο βοηθός.
  • Φάκελοι όπως node_modules, .venv και target μένουν στον υπολογιστή, όπως και τα αρχεία πάνω από 25 MB.
  • Αν το ίδιο αρχείο αλλάξει ταυτόχρονα και στα δύο σημεία, κρατιέται η εκδοχή του υπολογιστή και του Studio μπαίνει στο .strata-studio/conflicts.
  • Μετά τον πρώτο φάκελο, ο βοηθός ξεκινά μόνος του όταν συνδέεστε στον υπολογιστή (το απενεργοποιείτε από τη σελίδα ή το μενού του). Κατά τη σύνδεση ξεκινά αθόρυβα, χωρίς παράθυρο. Το εικονίδιό του είναι πράσινο όσο όλοι οι φάκελοι είναι συνδεδεμένοι· το μενού ανοίγει το παράθυρό του, συνδέει άλλον φάκελο ή τον κλείνει. Αν τον ξεκινήσετε ξανά, ανοίγει πάλι το παράθυρό του. Όταν δεν τρέχει, μπορείτε ακόμη να διαβάζετε και να αλλάζετε το αντίγραφο στο Studio· οι εντολές περιμένουν να επιστρέψει.
  • Οι servers που ξεκινά το έργο τρέχουν σε εκείνον τον υπολογιστή, οπότε η καρτέλα Live δεν μπορεί να τους δείξει.
  • Ένας web server που ξεκινά στον υπολογιστή σας ο βοηθός, μια εντολή ή ένα τερματικό του Studio φαίνεται κι αυτός στο Studio: το κουμπί με την υδρόγειο στον Explorer τον δείχνει και τον ανοίγει σε καρτέλα Live, και ο βοηθός μπορεί να τον δει με το view_page. Το πρόγραμμα βοηθός κάνει κάθε αίτημα στον υπολογιστή σας και στέλνει πίσω την απάντηση. Προγράμματα που ξεκινήσατε μόνοι σας έξω από το Studio δεν είναι ποτέ προσβάσιμα. Χρειάζεται βοηθό έκδοσης 0.06 ή νεότερης.
  • Για να σταματήσετε την κοινή χρήση, επιλέξτε Disconnect στο My computers. Το αντίγραφο στο Studio μένει, ως συνηθισμένος φάκελος.

Κινητά και tablet

Στο κινητό, οι καρτέλες στο κάτω μέρος αλλάζουν ανάμεσα σε Αρχεία, Επεξεργαστή, Συνομιλία και Τερματικό, και τα κουμπιά της πάνω μπάρας βρίσκονται στο φύλλο More. Οι ενέργειες ενός αρχείου βρίσκονται στο κουμπί μενού της γραμμής του. Στο tablet η λίστα αρχείων ανοίγει πάνω από τον επεξεργαστή, με τη συνομιλία δίπλα.

Όταν κάτι πάει στραβά

  • «Studio was updated»: πατήστε Reload για να πάρετε την πιο πρόσφατη σελίδα.
  • Δεν γίνεται τίποτα μετά την αποστολή: μπορεί να φορτώνει το μοντέλο (δείτε τη μπάρα), ή να έχει κάποιος άλλος τον βοηθό (δείτε την αίθουσα αναμονής).
  • Η εργασία σταμάτησε: η γραμμή στο τέλος λέει γιατί (όριο γύρων, κομμένη απάντηση, κύκλοι, σφάλματα). Το Continue συνήθως βοηθά. Για σφάλματα του μοντέλου, ελέγξτε ότι τρέχει ο διακομιστής μοντέλων σας (Ollama, llama.cpp, vLLM, LM Studio ή έναν Strata gateway).
  • Η απάντηση είναι σε λάθος γλώσσα: γράψτε το μήνυμά σας στη γλώσσα που θέλετε. Το Studio το λέει στο μοντέλο. Μια τελική απάντηση στα αγγλικά σε ελληνική συζήτηση στέλνεται πίσω μία φορά. Με τα μοντέλα Strata οι κινέζικοι, ιαπωνικοί, κορεατικοί, κυριλλικοί, αραβικοί, εβραϊκοί, ινδικοί, ταϊλανδέζικοι και βιετναμέζικοι χαρακτήρες δεν μπορούν να γραφτούν καθόλου, εκτός αν ζητήσετε μία από αυτές τις γλώσσες ή αν υπάρχουν ήδη στη συζήτηση. Μια λέξη με ελληνικά και λατινικά γράμματα μαζί («αρχείa») διορθώνεται όταν είναι σαφές ποια ελληνική λέξη εννοούσε· οι υπόλοιπες ανάμεικτες απαντήσεις στέλνονται πίσω μία φορά, και μια ανάμεικτη λέξη που μένει μετά από αυτό σβήνεται.
  • Διαχειριστές: οι δείκτες του μοντέλου (πάνω μπάρα) δείχνουν μνήμη, ταχύτητα και φόρτο, και το Loaded now δείχνει τι πιάνει αυτή τη στιγμή την κάρτα γραφικών και τη RAM: το γλωσσικό μοντέλο, το ComfyUI, τις μηχανές φωνής και ήχων, το Blender και ό,τι άλλο μεγάλο, το καθένα με τη VRAM και τη RAM του.
